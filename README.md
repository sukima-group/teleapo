## 🆕 v60：シフト管理の完成＋アポ報告の必須ヒアリング

### ① 15分刻み＋中抜け（休憩を何回でも）
日付をタップして開く画面で、**休憩を最大4回まで**登録できるようになりました。

- 例：9:30〜18:00 で **12:00-13:00 ／ 14:00-15:00 ／ 16:00-17:00** の3段中抜け
- 「＋ 休憩を追加」で何段でも追加、不要なものは「削除」
- **実働時間は休憩を差し引いて自動計算**され、その場で表示されます
- 入力ミスを防ぐチェック付き（休憩の重なり・逆転・勤務時間外・実働ゼロを警告）
- 時刻はすべて **8:00〜22:00 の15分刻み**（16:45 なども選択可）

### ② 自分の出勤予定がひと目で分かる
シフト画面に **「🗓 あなたの出勤予定」** を追加しました。
登録した日付・曜日・勤務時間・**休憩（中抜け）**・その日の実働時間を一覧表示します。
**表示されるのは本人の予定のみ**で、他のアポインターの予定は一切見えません。

### ③ 管理者：月次シフト表（誰がいつ出勤するか）
管理者ビューに **「📅 月次シフト表」** を新設しました。

- **1日ごとに、出勤人数と出勤者（名前・時間・休憩）** を一覧表示
- 月の切り替え（◀ ▶）に対応
- **「📗 スプレッドシートに出力」** で、川嶋メソッド_メイン に **「シフトカレンダー」シート**（日付／曜日／出勤人数／出勤者と時間）を生成します
- 元データは新設の **「シフト明細」シート**（申請のたびに、その人・その月の分を入れ替えて保存）
- **アポインター側からは他人のシフトを見る画面がありません**

### ④ アポ報告の強化
**⑴ 特定技能外国人の案件のヒアリング（該当時は必須）**
アポ入力画面の「特定技能外国人の案件です」にチェックを入れると、次の4項目が**必須**になります。

| 項目 | 入力形式 |
|---|---|
| 外国人雇用 | YES／NO |
| 特定技能 | YES／NO |
| 技人国（技術・人文知識・国際業務） | YES／NO |
| 外国人を採用する場合、誰が面接・採用決定するか | 自由記入（例：施設長 山田様） |

未入力のまま送信しようとすると、**不足項目を名指しで警告**して送信を止めます（報告漏れ防止）。
内容は報告メール本文と「アポイント」シートの新しい列にも記録されます。

**⑵ 録音音声の送付案内**
アポ入力画面に案内を常時表示します。

> 🎙 アポ取得時の録音音声をお送りください
> **音声送付先：楠 晶恵 様（a.kusunoki@sukimagroup.jp）**
> ボイスレコーダーから今回のアポの録音を探して、Gmailで送付してください。

「録音音声を送付しました」のチェックが付き、報告メールにも**送付済み／未送付（要対応）**が記載されます。

## ⚠️ デプロイ

1. **GAS**：「コード.gs」全消去 → `gas-code.txt` 貼付 → 保存 → 「デプロイを管理」→ ✏️ → **新しいバージョン** → デプロイ
2. **関数 `setupSheets` を1回実行**（「シフト明細」シートが作成されます）
3. **GitHub**：8ファイルを Upload → Commit ／ **全端末**：キャッシュクリア → ホーム画面に再追加

### 確認手順
1. ログイン画面に「**v60**」
2. アポインターで **シフト画面 → 日付タップ** → 開始・終了を選び、**「＋ 休憩を追加」を2〜3回**押して中抜けを登録 → 実働時間が減ることを確認 → 登録
3. シフト画面下の **「🗓 あなたの出勤予定」** に、日付・時間・休憩・実働が並ぶことを確認 → **「📩 申請する」**
4. 管理者（9999）→ **「📅 月次シフト表」→「🔄 シフト表を表示」** → 日ごとの出勤者が出ること
5. **「📗 スプレッドシートに出力」** → 川嶋メソッド_メイン に「シフトカレンダー」シートができること
6. アポ入力で **「特定技能外国人の案件です」にチェック** → 何も入れずに送信 → **不足項目が警告される**こと。入力後は送信でき、メールに4項目と録音送付状況が入ること

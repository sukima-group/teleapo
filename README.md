## 🆕 v93：v92が60点だった理由

### 問題は「1箇所を直しただけ」だったこと
v92では `extCfg is not defined` を修正しましたが、**同種の誤りが他の画面に無いことを確かめていませんでした**。
v78〜v91で多くの画面を追加しており、**同じ種類のエラーが他にも潜んでいる可能性**を排除できていませんでした。

### v93の解決：全画面を実際に描画して検査する仕組みを作りました
同梱の **`全画面検査ツール.js`** は、index.html の本体を実際に読み込み、
**86項目**（13画面 × 2権限 ＝ 26／パネルの各状態 25／**画面から呼ばれる関数 35個**）を実行して、
`〇〇 is not defined` のような実行時エラーを洗い出します。

```
$ node 全画面検査ツール.js index.html

✅ 本体スクリプトの読み込み: 成功
  検査できる関数: 35 個

画面数: 86 ／ 成功 86 ／ 失敗 0
✅ すべての画面が描画できました
```

### この検査ツールが本物であることの証明
**v91（バグがある状態）に対して実行し、実際にバグを検出できることを確認しました。**

```
$ node 全画面検査ツール.js （v91のindex.html）

画面数: 86 ／ 成功 85 ／ 失敗 1

── エラーが出た画面 ──
  ✗ 関数実行／openExtForm5
     extCfg is not defined
```

**検出できないツールでは意味がありません。**「バグがある版では失敗し、修正版では成功する」ことを両方で確認しています。

| 対象 | 件数 | 内容 |
|---|:--:|---|
| 画面 | 26 | login／home／call／list／appo／apoRec／shift／stats／history／appolist／cblist／meeting／admin を**アポインター・管理者の両方**で |

| 関数 | 35 | 画面のボタンから呼ばれる関数を**実際に呼び出して**エラーを検出 |

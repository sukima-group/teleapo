**計算のルール（決まりごと）**
- アポ売上＝**39,300円×件数**（商談日で計上）。**NKTのアポはアポ売上に含めず**、契約書1件回収ごとに65万円の成果報酬売上として登録します
- アポインターの原価：柏木＝月額115,000円＋アポ1件5,000円＋社会保険料（会社負担16%）／藤田＝時給1,150円／田中＝時給1,300円／片山＝時給1,300円＋社会保険料（16%）
- 損益分岐（件/月）＝その月の原価 ÷ アポ1件の粗利（39,300円−アポ報酬）。粗利50%ライン＝原価 ÷（39,300円×50%−アポ報酬）
- KPI配賦＝（年商目標−実績−予約済み）÷39,300円 ÷ 期末までのシフト時間 ＝「1時間あたり必要アポ」。これを各人の各日のシフト時間に掛けて目標にします。シフトが無い日は曜日パターン（祝日・年末年始は0）
- 入金消込：案件ごとに古い請求から順に入金を充当。振込手数料などの差額は990円まで「入金済(差額)」
- 金額は税抜、入金は税込。消費税は1円未満切り捨て

## 6. ふだんの使い方
- **毎日**：アポインターがいつもどおりアプリでアポを報告します。管理者は「📞 アポ台帳 →📥 アプリのアポ報告を取込」を押し、「👥 アポインター」で今日の損益分岐と差異を見ます
- **入金があったら**：PayPay銀行の明細CSVを「🏦 入出金 → 📥 銀行のCSVを取込」で取り込みます。名義で自動的に消し込まれます。別の口座や現金で受け取った分は「💴 売上・入金 → ＋入金を登録」で入れます
- **契約書・求人票を回収したら**：「💴 売上・入金 → ＋売上を登録」で、種類を「成果報酬」にし、元になったアポを選んで登録します（担当アポインターが自動で入ります）
- **新しい案件**：「📁 案件 → ＋案件を登録」で登録します。アポ一覧での呼び名と振込名義カナを入れておくと、取込と消込が自動になります
- **月初**：シフトが出そろったら「🎯 KPI・シフト」で稼働データを取得し、KPI目標に反映します
- **共有・保存**
  - 「📄 スプレッドシートに書き出す」で、メインのスプレッドシートに「財務_レポート_◯◯」の4シートを作ります
  - 「📊 Excelに出力」でExcelファイルにできます

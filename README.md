## 🆕 v87：60点だった理由

v86で「同期アプリ無料版＋自動複製」の仕組みは完成しました。しかし——

**同期アプリの無料版は1ファイル10MB（約21分）まで**です。それを超える通話は自動で送られません。
v86では**管理者だけがその一覧を見られる**状態で、**当のアポインター本人は「自分のどの通話が届いていないか」を知る手段がありませんでした**。
気づくのは管理者から指摘されたとき——これでは取りこぼしは減りません。

### 解決①：本人のホームに「録音が届いていない通話」を表示
```
📌 録音が届いていない通話（3件）
　この通話の録音を、上のボタンから送ってください。
　うち1件は長い通話のため、自動では送られません。

　08-15 14:30　◯◯株式会社　　　25分12秒 ⚠
　08-15 11:05　△△介護センター　 8分40秒
　08-14 16:20　□□ホーム　　　　12分03秒
```
- **録音が紐づいていない通話だけ**を新しい順に表示
- **⚠印＝自動では送られない長さ**（手動送信が必要）
- 20秒未満のごく短い通話は表示しません（誤タップ等を除外）
- 送信すると**自動で一覧から消えます**

これで、**その場で気づいて、その場で送れます**。

### 解決②：回収を1日2回に
**「🕐 昼(12時)＋夜(21時) の2回にする」** を追加しました。
昼にも回収するので、**取りこぼしをその日のうちに発見**できます。

### 解決③：Autosync無料版の設定カード（新規PDF）
`録音の自動保存_設定カード.pdf`（A4・2ページ・白黒印刷対応）
- 1ページ目：**無料版のままでよい**ことを明記した設定手順5ステップ
- 2ページ目：**5名分の「ログインするGmail」と「選ぶフォルダ」**の一覧、10MB制限の説明、設定後の流れ

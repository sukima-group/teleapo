スキマグループ合同会社

## 🆕 v77：「XLSXがない」を解消しました

### v76までが不十分だった理由
v76までは **「元になるExcelがドライブにあること」が前提**でした。
ドライブに `スキマグループ_経営管理システム.xlsx` が無ければ、設置できずに止まってしまいます。
**Excelが無いところから始められない**——これが最大の欠落でした。

### v77の解決：GASが41シートを自力で組み立てます
経営管理システムの**設計データ（33シート・5,303セル・数式3,267本・名前付き範囲46件）をコードに内蔵**しました。
Excelが無くても、**ボタン1つでドライブ上にスプレッドシートを新規作成**します。

| 状況 | v77の動き |
|---|---|
| ドライブにExcelがある | それを変換して使う（既存資産を優先） |
| **Excelが無い** | **システムが41シートを新規作成**（🏗 新規作成 と表示） |

作成後は、これまでどおり⑰日次活動ログへデータが投入され、②ダッシュボード・⑤アポインター・⑥テレアポKPI などが自動計算されます。

### 見つけて直した重大な欠陥
検証中、**名前付き範囲（TGT_SALES／ELAPSED_M など46件）が欠落**していると、
数式が `#NAME?` になることを発見しました。**エラー1,076件**が出ていました。
名前付き範囲を設計データに組み込み、**205件まで低減**。残りは LibreOffice が `IFS` 関数に未対応なためで、
**元の第5期ファイル自体も同条件で179件のエラーを出します**（同水準）。
**Googleスプレッドシートは `IFS` に対応しているため、実環境では解消します。**

## ✅ 検証（27/27 合格 ＋ 実ビルド比較 ＋ 回帰）
**設計データ 27項目**：33シートすべてを含む／総セル数5,303／数式3,267本／⑰日次活動ログの見出し（3行目・日付・アポインター・架電数…）／①設定のアポインターマスタ（14行H列・柏木幸代〜小澤幸枝）／②ダッシュボードの他シート参照／列幅・固定行・列名変換／日付セルの保持／**33シートすべてがグリッド化でき生成時に落ちない**こと。

**実ビルド比較**：内蔵した設計データから **実際にワークブックを組み立て直し**、⑰へ7行（架電270・アポ11）を投入して LibreOffice で再計算。⑧顧客分析・⑬収益分析・⑰日次活動ログ・㉙月次締めへの波及を確認し、**エラー件数を元ファイルと比較**（元179件／再構築205件＝同水準）。

**回帰**：v76の22項目・v74の28項目とも合格。

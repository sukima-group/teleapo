## 🆕 v47 の変更点

### ① 架電リストシートの自動作成（藤田・本郷・小澤）
「川嶋メソッド_メイン」スプレッドシートに、新メンバーの架電リスト用シートが無い状態でした。v47で**不足しているシートを自動作成**します。

- `setupSheets` 実行時に、**全メンバー分のリストシートを一括作成**（`setupMemberSheets`）
- シートには **見出し行（会社名／電話番号／担当者／住所）** を自動で設定。太字＋背景色＋1行目固定＋列幅調整済み
- **電話番号の列は「文字列」書式**に設定 → 先頭の 0 が消えません（例：03-1234-5678、080-xxxx-xxxx）
- **既存シートには一切触れません**（冪等）。何度実行してもデータは消えません
- 管理者ビューの「🩺 セットアップ診断」に **「📗 架電リストシートを作成」ボタン**を追加。スプレッドシートを開かなくてもアプリから作成できます
- アポインターの初回ログイン時・診断実行時にも、シートが無ければ見出し付きで自動作成されます

### ② 発信を「実際にかかる」状態へ近づける
**技術的な事実（正直にご説明します）**：スマートフォンは「アプリが勝手に電話をかけない」安全機構を持っており、**Webアプリから通話を開始することはOSレベルで不可能**です（当システムに限らず、あらゆるWebアプリで同じです）。そのため、発信画面までは自動で開けても、**最後の「通話」ボタンだけは押下が必要**です。

v47では、この1タップを**運用で消せる仕組み**と、SIM発信の確認手順を組み込みました。

- **⚙️ 自動タップ連携（新設）**：ONにすると、**間隔設定にかかわらず「保存＝即発信」**になり、待機画面を挟まず最短で発信画面が開きます
- **📖 設定手順ガイド（アプリ内）**：
  - **① 発信元SIMの確認**：設定 → 接続 → **SIMマネージャー** → 「通話」の優先SIMが **080-7049-5533** であることを確認（SIM1枚なら自動的にこの番号で発信されます）
  - **② 通話ボタンの自動押下**：自動化アプリ **MacroDroid（無料）** で「トリガー：アプリ起動→電話／アクション：2秒待機／UI操作：テキスト『通話』をクリック」のマクロを作ると、**完全に0タップ**で連続発信できます
- 発信画面のオーバーレイに、自動化アプリが認識しやすいよう**固定ラベル「通話」**を配置しました

## ⚠️ デプロイ

**GAS再デプロイ（新しいバージョン）が必須**です。

1. **GAS**：script.google.com →「コード.gs」全消去→ `gas-code.txt` 貼付→保存→「デプロイを管理」→✏️→**新しいバージョン**→デプロイ
2. **★ 重要**：エディタ上部の関数プルダウンで **`setupSheets`** を選び「**実行**」を1回押してください。これで**藤田・本郷・小澤のシートが作成**されます（既存シートは変更されません）
   - ※ アプリの管理者画面「🩺 セットアップ診断 →📗 架電リストシートを作成」でも同じことができます
3. **GitHub**：sukima-group/teleapo → Upload files → 8ファイル → Commit
4. **全端末**：キャッシュクリア→ホーム画面再追加

### Step 5: 確認
1. スプレッドシートに **「藤田」「本郷」「小澤」** タブができ、1行目に **会社名／電話番号／担当者／住所** が入っている
2. そこへリストを貼り付ける（または各自が「リスト読込」でアップロード）
3. PIN 101 でログイン → リストが表示され、発信できる
4. 通話画面 →「⚙️ 自動タップ連携」をON →「📖 設定手順」でSIMと自動化の手順を確認
5. 結果を保存 → **待機なしで次の会社の発信画面が開く** → 通話ボタンを押す（MacroDroid設定済みなら自動）

## 🆕 v103：v102が60点だった理由

v102は「貼り付け先のタブを作る」ところまででした。
しかし**リストを入れる作業そのものは、スプレッドシートを開いて手で貼る**ままでした。
中村さん・田中さん・片山さんの3名分、それぞれのタブを開いて貼る——ここが残った手間であり、ミスの入り口でした。

### 解決：📥 リストを登録する（管理画面・新設）
**スプレッドシートを一切開かずに**、アプリから直接登録できます。

```
📥 リストを登録する（スプレッドシートを開かずに）
　[ 📂 Excel／CSVを選ぶ ]   [ 📋 貼り付けた表を読み取る ]
　┌────────────────────────────────────┐
　│ Excelで範囲をコピーして、ここに貼り付け │
　└────────────────────────────────────┘
　✅ 300件を読み取りました
　　会社名        電話番号       担当者  住所
　　株式会社A     03-1111-0001   山田    東京都
　　…ほか297件
　[ 👤 1人に登録 ]  [ 👥 複数人へ均等配分 ]
　　✓ 田中久美子  ✓ 中村花林  ✓ 片山佳代
　　→ 3名に約100件ずつ配分します（上から順に輪番）
　[ 📤 登録する ]
```

**3つの入れ方に対応**
| 入れ方 | 操作 |
|---|---|
| **Excel／CSVファイル** | ファイルを選ぶだけ（.xlsx／.csv／Shift-JISも自動判別） |
| **コピー＆ペースト** | Excelやスプレッドシートで範囲をコピー → 貼り付け → 読み取る |
| どちらも | **1人に登録** or **複数人へ均等配分**を選んで登録 |

**列の並びが違っても大丈夫です。** 1行目の見出し（会社名／施設名／電話／TEL／担当者／施設長／住所／所在地 など）から自動で判定します。見出しが無い場合は「会社名・電話番号・担当者・住所」の順とみなします。

**均等配分**は上から順に輪番で振り分けるので、300件を3名なら100件ずつ、偏りません。

### 夜間処理でも経営システムの名簿を合わせます
新メンバーの名前が経営管理システムに出ない問題は、**毎晩の自動処理でも名簿同期**を走らせることで、ボタンの押し忘れがあっても翌朝には揃うようにしました。

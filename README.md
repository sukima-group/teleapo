# 川嶋メソッド テレアポ業務管理システム v74（夜間自動処理の統合）

スキマグループ合同会社

## ご質問「録音も自動保存される？」への答え

**はい、自動保存されます。** ただしv73までは、その仕組みに3つの弱点がありました。v74で解消しています。

| v73までの弱点 | v74での解決 |
|---|---|
| 録音の取込・経営更新・バックアップが**別々のトリガー**で、実行順序が保証されていなかった（録音を紐づける前に経営システムが更新される可能性） | **1本の夜間パイプライン**に統合し、正しい順序で実行 |
| 設定するボタンが分散し、**どれをONにしたか分からない** | **「🌙 夜間自動処理」1か所**でON／OFF。他の重複トリガーは自動で片付け |
| **本当に毎晩動いたのか確かめられない** | **実行ログ・履歴表示・見張り（watchdog）・1通の結果メール** |

## 🆕 v74：毎晩この順番で、ひとりでに回ります

```
① 録音の吸い上げ（メール・受信箱 → 担当者フォルダ／年月／日）
② 録音を架電記録に紐づけ（電話番号＋時刻）
③ 経営連携の再集計（即時反映のズレを補正）
④ 経営管理システム（21シート）の更新
⑤ バックアップ
        ↓
   結果を1通のメールで通知
```

**順序に意味があります。** ①②で録音が揃ってから④の経営システムを更新するため、録音カバー率まで含めた正しい数字になります。

### 途中で失敗しても止まりません
どれか1つが失敗しても**後続はすべて実行**され、メールには
`✅ 録音を架電記録に紐づけ：11件` `⚠️ 録音の吸い上げ：Gmailを読めません`
のように**成功と失敗が項目ごとに**並びます。何を直せばよいか一目で分かります。

### 「動いているか」を見張ります
管理画面に**最終成功日時**と判定を表示します。
`正常` ／ `前日のまま` ／ `2日間停止` ／ `3日以上停止` ／ `未実行`
直近7回の実行履歴（結果・所要秒・録音件数・紐づけ件数・投入行数）も一覧で確認できます。

### ▶ 今すぐ実行して確かめる
設定直後に **「▶ 今すぐ実行して確かめる」** を押せば、夜を待たずに全工程を動かして結果を確認できます（2〜4分）。

## ✅ 検証（42/42 合格）
**パイプライン 28項目**：実行順序（吸い上げが最初・紐づけがその直後・経営更新は紐づけより後・バックアップが最後）／全成功時の判定と所要秒と本文（実績値が入る）／**途中失敗でも後続3手順が実行される**／失敗した手順を名指し・原因が本文に入る・成功分は✅表示／複数失敗時の件数／見張り判定（当日=正常・1日=前日のまま・2日=2日間停止・3日=3日以上停止・未実行）／未実行の手順は失敗に数えず「－」表示。
**回帰 14項目**：11名の名簿整合／即時反映の増分／実働計算／録音の判定・日時解釈・番号抽出・差出人判別・フォルダ名・紐づけ／⑪の列位置と行組み立て。

## ⚠️ デプロイと設定
1. **GAS**：「コード.gs」全消去 → `gas-code.txt` 貼付 → 保存 → **新しいバージョン**でデプロイ
2. **GitHub**：8ファイル Upload → Commit ／ **全端末**：キャッシュクリア → 再追加
3. 管理者 → **「🌙 夜間自動処理」→ 実行時刻（20時／21時／23時）を選ぶ**
   → 古いトリガーは自動で片付き、これ1本になります
4. **「▶ 今すぐ実行して確かめる」** を押して、5項目すべてに ✅ が付くことを確認

> 💡 実行時刻は**アポインター全員の退勤後**（21時か23時）がおすすめです。当日の録音と架電結果が揃った状態で処理されます。

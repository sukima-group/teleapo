# 川嶋メソッド テレアポ業務管理システム v80（PC発信の設定が見つかる・キーボードで完結）

スキマグループ合同会社｜Windows PC ／ Mac ／ Galaxy A25 5G

## 🆕 v80：60点だった本当の原因

### 原因：PC発信の切替ボタンが「隠れていた」
v79で機能自体は作りましたが、**切替ボタンを「オートコールがONのときだけ表示される場所」に置いていました**。
初めてPCで開いた方は、**オートコールをONにしない限りボタンに辿り着けません**。
機能があっても**見つからなければ無いのと同じ**——これが最大の欠落でした。

### 修正1：常に見える場所へ
**パソコンで開けば、オートコールのON/OFFに関係なく必ず表示**されます。

```
[💻 PC発信 ON]  [📖 設定]  [📡 発信テスト]        本日 12件
⌨ Enter=発信 → 通話後 1〜6で結果を選び Enterで保存／R=かけ直す Esc=取消
```

### 修正2：📡 発信テスト（新設）
**設定が正しいかを、架電リストを使わずに確かめられます。**
ボタンを押して、かけても差し支えない番号（会社の代表番号など）を入力すると、その番号へ発信を試みます。
スマートフォン連携が開いてGalaxyから発信されれば、**設定は完了**です。

### 修正3：キーボードだけで一周できます（新設）
PCでは手がキーボードにあるため、マウス操作は流れを止めます。

| キー | 動作 |
|---|---|
| **Enter** | 発信（通話前）／**保存**（通話中） |
| **1〜6** | 結果を選ぶ（**画面のボタンに書いてある番号と同じ**）<br>1 アポ獲得／2 再架電／3 不在／4 断り／5 不通／6 その他 |
| **R** | かけ直す |
| **Esc** | 発信を取り消す（記録しません） |
| **N** | 次の会社へ |

**誤操作を防ぐ設計**：通話中のEnterは「保存」なので**二重発信しません**。メモ入力中はキー操作が一切効きません。端末（スマホ）モードでは無効です。

## ⚠️ 使い方（PCで開いたとき）

1. **GitHub**：8ファイル Upload → Commit（GASの変更はありません）
2. PCでキャッシュをクリアして開き直す → ログイン → 通話画面
3. 画面に **[💻 PC発信 ON]** のバーが出ていることを確認
4. **[📡 発信テスト]** を押し、会社の代表番号などを入れて発信を確認
   - 発信されれば設定完了。されなければ **[📖 設定]** の5ステップを確認
5. あとは **Enter → 通話 → 1〜6 → Enter** の繰り返しで回せます

> **Windows**：初回の「スマートフォン連携を開きますか」で**「常に許可する」にチェック**。これを忘れると毎回確認が出て流れが止まります。
> **Mac**：番号が自動でコピーされます。Galaxyの電話アプリに貼り付けて発信してください（画面の進行は同じです）。

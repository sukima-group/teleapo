## 🆕 v94：未設定でも押せない状態を解消しました

### これまでの動き
「取込」「反映」のボタンは**設定済みの方にしか表示されない**仕様でした。
未設定の4名（小澤・榮・柏木・竹之内）は**ボタンそのものが無く、何をすればよいか分からない**状態でした。

### v94：3つのボタンを全員に常時表示します
```
柏木幸代 091     未設定    —     [設定] [取込] [反映]
  ┗ [ 柏木幸代 さんのスプレッドシートURLを貼る          ] [設定]
竹之内優子 098   未設定    —     [設定] [取込] [反映]
  ┗ [ 竹之内優子 さんのスプレッドシートURLを貼る        ] [設定]
藤田直美 101    ✅設定済  16:04  [設定] [取込] [反映]
```

**① 未設定の方の行に、URL入力欄が直接出ます**
その方のスプレッドシートURLを貼って**[設定]を押すだけ**。1名ずつその場で完了します。
成功すると「✅ 柏木幸代 さん設定完了（タブ「柏木」）」と出て、一覧が更新されます。

**② 未設定のまま「取込」「反映」を押した場合**
何も起きずに終わるのではなく、こう案内します。
```
柏木幸代 さんはスプレッドシートが未設定のため、取込できません。
今すぐ設定しますか？（この方のスプレッドシートURLを貼るだけです）
　　　　　　　　　　　　　　[ OK ]  [ キャンセル ]
```
OKを押すと**入力フォームが開き、その方の欄が自動で選択されます**。迷う余地がありません。

**③ 状態が色で分かります**
設定済みは色つき、未設定は灰色。押せるが未設定、ということが見て分かります。

## ⚠️ 導入と使い方

1. **GitHub**：8ファイル Upload → Commit（**GASの変更はありません**）
2. **全端末・PC**：キャッシュクリア → 開き直す

### 設定の手順（1名あたり15秒）
1. 管理者 →「🔗 元スプレッドシート連携」→「🔄 連携設定を表示」
2. **未設定の方の行の下に黄色い入力欄**が出ます
3. その方のスプレッドシートを開き、**アドレスバーのURLをコピーして貼付**
4. **[設定]** を押す → 「✅ 設定完了（タブ「〇〇」）」
5. 4名分を繰り返す
6. 全員が「✅ 設定済」になったら **「🔁 全員分の『取込 → 反映』を実行」**

> ⚠️ 「開けません」と出た場合は、そのスプレッドシートを **hr.ashikaga@gmail.com に「編集者」で共有**してから、もう一度[設定]を押してください。

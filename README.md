## 🆕 v62：本日の稼働予定の表示＋管理者向け実績集計

### ① 既存の勤務表をそのまま取り込めます（2形式に自動対応）
お送りいただいた3名分の勤務表は、形式が2種類ありました。**どちらも自動で判別**して読み込みます。

| 形式 | 例 | 読み取り方 |
|---|---|---|
| **午前/午後形式**（柏木さん） | 午前 10:00-12:00 ／ 午後 13:00-17:45 | 勤務 10:00〜17:45、**中抜け 12:00-13:00** として取り込み → 実働 6.75h |
| **開始終了＋休憩分形式**（竹之内さん・藤田さん） | 9:30-16:30 ／ 休憩60分 | 勤務 09:30〜16:30、休憩60分を控除 → 実働 6.00h |

- 見出し行は先頭5行以内から自動検出。日付は「8/3」「8月3日」「2026-08-03」「3」いずれも解釈します
- **空欄・「-」・「×」の日は出勤なし**として取り込みません
- 管理者ビューの **「📥 既存の勤務表シートからシフトを取り込む」** から実行します

### ② 本日の稼働予定をホーム画面に表示（士気を高める）
アポインターのホーム画面いちばん上に、**その日の勤務時間**を大きく表示します。時間帯によって表示が変わります。

| いまの状態 | 表示 |
|---|---|
| 開始前 | ⏳ **開始まで あと◯時間◯分** ／「今日も一件一件、丁寧にいきましょう」 |
| 稼働中 | 🔥 **稼働中 — 残り ◯時間◯分** ／「ここまで◯件架電・アポ◯件。この調子でいきましょう」 |
| 休憩中 | ☕ **休憩中（12:00〜13:00）** ／「しっかり休んで、後半に備えましょう」 |
| 終了後 | 🎉 **本日の稼働時間は終了しました** ／「退勤を押し忘れないでください」 |

**進捗バー**で1日の経過が一目で分かり、**稼働予定時間（6.75h など）**と**休憩時間帯**も表示します。

### ③ 管理者：実績集計（日ごと／月間合計・日平均）
管理者ビューに **「📊 実績集計」** を新設。アポインターごとに次を集計します。

**稼働実績(h)／アポ獲得数／架電件数／架電リスト数／アポ率(%)**

- **日ごとの明細**（名前をタップで展開）＋ **▼月間合計** ＋ **▼日平均（稼働日数ベース）**
- 全員合計のサマリー（稼働・アポ・架電・アポ率）を上部に表示
- **「📗 スプレッドシートに出力」** で川嶋メソッド_メインに **「実績集計」シート**を生成
- 集計元：稼働＝勤怠シート（出勤〜退勤−休憩）／アポ＝アポイントシート／架電＝架電結果シート／リスト数＝各自のリストシート
- **アポインターからは見えません**（管理者ビュー限定）

1. **GAS**：「コード.gs」全消去 → `gas-code.txt` 貼付 → 保存 → 「デプロイを管理」→ ✏️ → **新しいバージョン** → デプロイ
2. **関数 `setupSheets` を1回実行**
3. **勤務表のスプレッドシートを hr.ashikaga@gmail.com に編集権限で共有**
4. **GitHub**：8ファイルを Upload → Commit ／ **全端末**：キャッシュクリア → ホーム画面に再追加

### 確認手順
1. ログイン画面に「**v62**」
2. 管理者 → 連携パネルの「⚡ 全員まとめて設定」に**勤務表のURL**を入れて「📑 タブを取得してメンバーに自動割当」（各自のタブを割り当てる）
3. **「📊 実績集計」→ 対象月を選び →「📥 既存の勤務表シートからシフトを取り込む」** → 「◯名分のシフトを取り込みました」
4. **「📅 月次シフト表」→「🔄 シフト表を表示」** → 日ごとの出勤者が入っていること
5. アポインター（例：柏木さん）でログイン → **ホーム最上部に「本日の稼働予定 10:00〜17:45 ／ 6h45m」**と、いまの状況（開始まで／稼働中／休憩中）が出ること
6. **「📊 実績集計」→「🔄 実績を集計」** → 名前をタップして日ごとの明細・月間合計・日平均が出ること →「📗 スプレッドシートに出力」

# 川嶋メソッド テレアポ業務管理システム v106（📥 シフト取込・📐 損益分岐）

スキマグループ合同会社｜2026年10月18日

「💹 収支・KPI管理」に **📐 損益分岐** タブを追加しました。各アポインターの **シフト（勤務表）をExcelのまま取り込み**、
**アポインターごと** と **全員を合わせた全体** の損益分岐点を、**月間** と **年間** で確認できます。
取り込みは「確認してから登録」で、同じファイルを何度取り込んでも結果は変わりません。Excelの読み書きはアプリに内蔵したので、ネットにつながっていなくても動きます。

> サーバー（Apps Script の gas-code.txt）は **v105 から1文字も変えていません**。GitHub に `index.html` と `sw.js` を上げるだけで使えます。

> 品質の確かめ方：作った本人のテストだけでなく、**別の担当がコードだけを読んで壊しにいく独立レビューを11回**行い、見つかった問題（1回目13件・2回目21件・3回目18件・4回目15件・5回目18件・6回目12件・7回目7件・8回目7件・9回目11件・10回目14件・11回目9件）を直しました（見出しが無いと読み方が1つに決まらない表は、どう読んだかを要確認で知らせます）。3回目からは「直す前の版と直した後の版に、正解のある表を数千〜数万通り読ませて比べる」やり方で、直したことによる新しい誤り（副作用）も探しています。どの問題にも「直す前は失敗し、直した後は合格する」テストを付け、わざと誤りを入れて見つけられるかも確かめています（第5章）。

## 2. 取り込みのフォーマット

### 2-1. 標準テンプレート（1行＝1人の1日）
アプリの「📄 取込テンプレート」または `templates/シフト取込テンプレート.xlsx`（記入例・説明・入力規則つき）。**いちばん確実なのはこの形です。**

| 列 | 必須 | 書き方 |
|---|:-:|---|
| 氏名 | ○ | 報酬マスタの氏名（姓だけでも1人に決まればOK。「さま」・空白・異体字（澤/沢・嶋/島・齋/斉/斎など）は気にしなくて大丈夫） |
| PIN（任意） | | アプリのPIN。同じ姓の人がいるときに確実に区別できます。**名前と合わないときは自動で決めず、確認画面で選びます** |
| 日付 | ○ | 2026/10/5（Excelの日付）。年を省略した 10/5 も可（表の上の年月・曜日の列・期から判断し、**12月→1月は翌年**） |
| 開始・終了 | | 9:30 の形。休みの日は空欄。日をまたぐときは 25:00・翌1:00・1:00 のどれでも |
| 休憩（分） | | **休憩の合計**。60 または 60分（休憩開始・終了も入れるなら合計） |
| 休憩開始・休憩終了 | | 午前・午後に分かれた勤務は「午前の終了」「午後の開始」 |
| 実働（時間・任意） | | 入れると時刻からの計算と照合（違えば要確認）。休憩が空欄なら、開始〜終了との差を休憩とみなします |
| 時給（円・任意） | | その日の時給（改定前の時給の記録など）。空欄なら報酬マスタ（改定の記録を含む） |
| 備考 | | 自由（休・× なども可） |

### 2-2. これまでの勤務表もそのまま読めます
見出しがあれば見出しで、無ければ中身（日付・曜日・時刻・「○分」・小数）と **「開始〜終了 − 休憩 ＝ 実働」の整合** から列の役割を決めます。

| 並び（例） | 読み方 |
|---|---|
| 名前の行（田中 久美子 さま・時給1,100円）の下に 日付／曜日／開始／終了／開始／終了／実働（**ご提供の形**） | 午前と午後の2区間。午後だけ・午前だけ・休み（0.00 や空欄）の日もOK。名前の行ごとに人を分けます |
| ↑の時刻を「10.00」「1000」「10」（時だけ）・Excelの数（9.3・9.5）で打った表 | 同じ書き方の4列を午前・午後、2列を開始・終了として読みます（読み替えはお知らせ）。**勤務が1日だけの人**も、同じ貼り付けのほかの人と同じ列で読みます |
| 日付／曜日／開始／終了／休憩60分／実働／業務内容 | 開始〜終了から休憩を引く。休憩が「60」（数だけ）や「1:00」でも、実働との整合で休憩の列と分かります |
| 日付／出勤／退勤／実働（休憩の欄が無い） | 開始〜終了と実働の差（15〜90分）を休憩とみなします |
| 日付／出勤予定／退勤予定／出勤／退勤・2段の見出し（シフト｜実績 の下に 開始｜終了） | 実績を使い、実績が空の日（これからの日）は予定を使います |
| 2段の見出し（午前・午後の下に 開始｜終了、勤務時間の下に 自｜至・始｜終・IN｜OUT、(時刻)｜(分)） | 上下をつないで読みます |
| 勤務時間の欄に「9:00～18:00」「13-17」「9-18」（Excelが日付にしたもの） | 1つのセルの開始〜終了として読みます。日付・曜日との間に「出勤」「○」「早番」の列があっても大丈夫です。表の右の備考の「13-15」のようなメモ・時刻と違う時間帯の日がある列は勤務時間にしません（時刻の無い日にもあれば、要確認で知らせます）。開始・終了の無い日を予定の時間帯で入れたときは知らせます（過ぎた日は要確認） |
| 横に人が並ぶ表（日付｜田中｜藤田 の下に 9:00～13:00 や 4） | 人ごとの列として読みます（足し合わせない）。名前の行と表の間の注意書き（※時間は休憩を除く）・フリガナ・(時間) の行、表のあとの合計・以上・次の週の表があっても大丈夫です |
| 1人分の表が横に2つ並ぶ（田中の 日付｜開始｜終了 の右に 藤田の 日付｜開始｜終了） | 表ごとに、その表の名前の人として読みます（片方の人が全部休みでも、片方の人だけ交通費・備考の列を書いていても、1日2行（午前の行・午後の行）でも、日付の右に氏名の列があっても。上の「田中久美子」「氏名｜田中」「氏名：田中」「田中 さま」、見出しの行の中の「田中｜日付｜開始…」、表ごとの氏名の列、表ごとの時給も）。1つの見出しの下に何組並んでも、人によって時刻の打ち方が違っても、片方の人が全部休みでも大丈夫です。名前が無ければ、2つの表で同じ日に勤務が無く、日付が揃ってずれているときだけ同じ人の前半・後半です（名前の行の右の「担当：◯◯」は表の人にしません） |
| タイムカードの書き出し（出勤日｜出勤時刻｜退勤日｜退勤時刻、2段の見出し 出勤｜退勤 の下に 日付｜時刻） | 1つの表として読みます（退勤日が翌日の夜勤も） |
| 2つ目の日付の列（日付…｜アポ日｜件数、申請日、提出日｜時給、予定日｜…｜実施日） | 勤務の日付は1つ目の日付の列です。表を2つに分けたり、アポ日を勤務の日にしたりしません（時給はそのまま使います）。全部の行に同じ日がある提出日・行の最後の申請日も同じです。横に並ぶ表を分けられないときは、右の表の時刻を左の日付で読まず、読まなかったことを知らせます |
| 時刻が「0930」「9.30」「9時半」「翌1:00」 | 時刻として読みます（読み替えた場合は表ごとに1回お知らせ）。小数の時間で書いた表（17.75 がある）では 9.25 は 9:15 です |
| 見出しの無い数だけの2列「9.00｜13.50」「9.00｜21.00」「13｜14」 | 開始・終了として読み、要確認で知らせます。「8｜20」（実働｜架電数）・「7｜0.5」（実働｜残業）は実働として読みます |
| 実働と拘束時間・予定の時間の両方の列（見出しなし） | 開始〜終了と同じ長さの列と、日によってそれより15〜90分短い列があるとき、6時間を超える日の休憩（法定：45分、8時間を超えると60分）、数の形（予定の時間は「4.00」「5.00」のちょうどの時間）、休憩の決まりの形（休憩のある日は休憩の無い日より長い）の順に、「拘束時間｜実働」か「実働｜予定の時間」かを決めます。どちらに読んだかは必ず知らせます（法定の休憩で決まらないときは要確認）。アポ数の列は実働にしません |
| 時刻の形の時間の列（拘束 7:00｜実働 6:15、実働 7:00｜休憩 1:00、移動「0｜0:20」） | 開始〜終了の長さとの関係で、拘束・実働・休憩を見分けます（実働が開始〜終了と同じ長さなら、「0:20」は休憩にしません） |
| Excel の曜日の列（=A3 を「aaa」の書式にした日付） | 曜日として読みます（日にちの列が数だけの表では、その日付を使います） |
| 日付が「1」「2」…・「1(木)」「1日 木曜日」 | 表の上・シート名・ファイル名の「2026年10月」で月を決めます。16日〜翌15日のような締めの表は「期間：2026年10月16日～2026年11月15日」と書くと確実です（期間は「～」「自｜至」「期間」の印があるときだけ。締日・支払日などの事務の日付は期間にしません） |
| ×・-・休・公休・欠勤 | 休み（0時間）。「\」「/」など意味の分からない記号は休み扱いにして要確認で知らせます |
| 人ごとのシート・上の行に「田中 久美子 さま」「時給1,100円」「【藤田】」「藤田直美：10月分」 | シート名か上の行の名前・時給を使います。1枚に何人分あっても名前の行（見出しの左の名前も）で区切ります |
| 所属・部署・フリガナ・承認者・判子の欄（承認｜確認 の下の名前）・期間・作成日などの行 | 名前には使いません（その値がほかの人の名前でも）。「氏名」の欄の名前は使います |
| 金額（実働×時給・交通費つき）・交通費の列（見出しの無い表） | 時給にしません（時給の列は 900〜5,000円の数のとき。実働と一緒に増える数は金額です。表の上に「時給1200円」があれば、それとどの日も違う数の列は時給にしません。報酬マスタと違う時給は、取り込む前に知らせます） |
| 午前と午後を別の行に書いた日 | 時刻が重ならなければ1日の勤務にまとめます |

### 2-3. 取り込みのルール
- **同じ人・同じ日はあとから取り込んだ内容で上書き**。内容が同じなら何も変わりません（送信もしません）
- **行の無い日**は「休み（0時間）」か「曜日パターンのまま」を選べます。休みにするのは、**その人の表（シート・名前の区切り）の最初〜最後の日の中で、行のある月だけ**です（7月と10月の表なら8〜9月は触りません）
- アプリの「⤓ 登録済みシフトを保存」で作ったファイル（シート名「登録済みシフト」）は、取り込み直しても行の無い日を休みにしません
- 同じ人が「PINあり」「PINなし」や「田中」「田中久美子」のように別の書き方で出てきても、名簿の同じ人に決まれば1人にまとめます。名簿に無い人どうしは、確認画面で「新しく登録する◯◯と同じ人」を選べます
- 人ごとに **「取り込まない」** を選べます
- **見出しの無い表で読み方が1つに決まらないとき**（数だけの「9｜18」が開始・終了か実働と件数か、休憩らしい数の列で休憩のある日が少ない、0.5・1 の数が休憩か残業か など）は、いちばんありそうな読み方にして **要確認で知らせます**。1行目に見出し（日付・開始・終了・休憩・実働）を付ければ確実です
- **要確認**（取り込む前に行番号つきで表示）：読めない時刻、時刻の不足、記載の実働との食い違い（時刻の計算を使います）、読めない記号、法定休憩の不足（6時間超で45分・8時間超で60分）、曜日と日付の食い違い（年・月の間違い）、**他の行から2か月以上離れた日付**（年の打ち間違い。休みで埋める範囲には入れません）、今日から離れすぎた日付、同じ日の行が2つで時刻が重なる（その日は取り込まない）、日付が読めない行、PINと名前の食い違い、名簿の似た名前、月額固定の人の時給、ファイルの時給と報酬マスタの違い、見出しの無い表の読み方、備考とみた時間帯
- 取り込んだシフトは「取り込んだシフト（人×月）」の 🗑 で消すと、その月は曜日パターン（仮）に戻ります

## 3. 計算のルール

| 項目 | 式 |
|---|---|
| 原価（1人・1か月） | 時給×シフト時間（＋法定の割増）＋月額固定＋社会保険料（会社負担）。時給は「その日の時給（取込）」→「報酬の改定（適用開始日）」→「報酬マスタ」の順 |
| 使う時間 | 予定（損益分岐の元）：**取り込んだシフト** → アプリのシフト申請 → 曜日パターン（祝日・休業日は0）。過去の日の実際の原価：取り込んだ勤務表 → 勤怠の打刻 → 予定 |
| アポ1件の粗利 | 標準アポ単価（39,300円）−アポ報酬（社会保険料込み） |
| 個人の損益分岐（件） | その月の原価 ÷ アポ1件の粗利 |
| 全体の損益分岐（件） | （全員の原価＋共通固定費）÷ **加重平均の粗利**（重み＝各人のシフト時間＝アポの構成比）。管理会計のCVP分析（複数製品の損益分岐）と同じ。全員の粗利が同じなら「各人の損益分岐の合計」と一致 |
| 損益分岐の売上 | 損益分岐（件）× 標準アポ単価 |
| 年間 | 各月の損益分岐の合計（人員・時給・シフトが月ごとに違っても、そのまま足せる） |
| **入社日・退職日** | 月額・社会保険の定額は**在籍した暦日で按分**（退職した後・入社する前の月はかけない）。損益分岐の原価と見込みの原価は同じ値になります |
| 停止中の人 | シフト・勤怠・アポの記録がある月は含める（記録の無い月の月額はかけない） |
| 法定の割増（雇用・時給の人） | 1日8時間超・週40時間超（日曜始まり）・22〜翌5時に25%（労働基準法37条）。設定で切れます |
| 月の途中の改定 | 月額は暦日で按分。時給はその日から |

## 7. ふだんの使い方
- **月初・月末**：勤務表を取り込みます（Excelのまま。人ごとのシートでも、1枚に全員でも可）。**新しい月・新しいアポインターの分も、同じ手順で何度でも登録できます**（同じ人・同じ日は上書き、同じ内容は変化なし）
- **時給が変わったとき**：報酬マスタの「報酬の改定」に適用開始日と金額を足します（上の金額を直接書き換えると過去の月も変わります）
- **新しいアポインター**：取り込んだときに名簿に無ければ、確認画面で時給を入れて登録できます。似た名前が名簿にあるときは知らせが出るので、同じ人なら名簿の人を選んでください
- **確認**：📐 損益分岐（全体と人別・月間/年間）、👥 アポインター（日別。取り込んだ日は「取」、仮は「仮」）
- **要確認が出たとき**：行番号の行を直して取り込み直します。見出しの無い表の読み方の知らせなら、1行目に見出し（日付・開始・終了・休憩・実働）を付けると確実です
- **直したいとき**：勤務表を直して取り込み直すか、「⤓ 登録済みシフトを保存」したExcelを直して取り込みます（人×日で上書き）

## 8. まだ対応していないこと
- 法定休日の割増（35%）、月60時間を超える時間外（50%）、有給休暇の賃金
- 見出しの無い表で、読み方が1つに決まらないもの（いちばんありそうな読み方にして、要確認で知らせます。1行目に見出しを付けると確実です）
  - 数だけの2列（「9｜18」「9.5｜14.5」「9｜21」）：開始・終了か、実働と件数か
  - 休憩らしい数の列で休憩のある日が少ないもの、0.5・1 の数（休憩の時間か残業か）：引かずに知らせます
  - 勤務の行が1行だけの人の、時だけの2列（「10｜12」）：同じ貼り付けにほかの人の行があれば、その形で読みます
  - 記載の実働と時刻が違うときは時刻の計算を使います（切り捨てた実働を使うときは、時刻を直すか見出しのある表にしてください）
- 人ごとに開始・終了の2列が横に並ぶ表（田中の開始｜終了｜藤田の開始｜終了。見出しがあっても）・月×日のカレンダー型（人が縦、日が横）は読めません（取り込めない理由を出します。標準テンプレートか、人ごとのシートにしてください）
- 見出しの無い表で、Excel が日付に変えた「9-13」（9月13日）だけの列は、勤務時間と分かりません（1行目に「時間帯」の見出しを付ければ読みます）。実働の右に「通話時間 1:30」のような時刻の形の列がある表も、読めないことがあります（要確認で知らせます）
- 見出しの無い表で、時刻の列の右に「9:00～13:00」が時刻の無い日にだけある列は、備考として読みます（要確認で知らせます。予定の時間帯なら見出しを付けてください）。時刻の列のすぐ右の時間帯の列は予定の時間帯として、開始・終了の無い日に使います（使った日を知らせます）
- 名前の無い横に2つ並ぶ「日付｜実働」の表で、右の表がアポ日と件数のような別の内容でも、勤務の日が重ならず日付が揃ってずれていると、前半・後半として読むことがあります（見出しを付けると確実です）
- 同じ人の前半｜後半が1日おきに並ぶ表（左に10/1、右に10/2 …）は、どちらの表にも開始・終了があるときだけ分けます（表ごとに時刻が1つの夜勤のタイムカード「出勤日｜出勤時刻｜退勤日｜退勤時刻」は1つの表）。分けられないときは、右の表を左の日付で読まず、読まなかったことを知らせます
- 見出しの無い「拘束｜実働」「実働｜予定」で、差のある日が1〜2日だけのときは、どちらか決めきれないことがあります（どちらに読んだかを要確認で知らせます。1行目に見出しを付けると確実です）
- 横に2つ並ぶ表の上に名前が1つずつ（「田中 久美子 さま｜…｜藤田直美」）あれば、日付が前半・後半のように続いていても2人の表として読みます（そう読んだことを知らせます。同じ人なら、右の名前を消すか「担当：」を付けてください）
- 見出しの無い表で、日付の右に氏名の列がある形（日付｜氏名｜開始｜終了。横に並ぶ表も）の、その期間ずっと休みの人の表は「列を判定できません」になります（ほかの人は取り込めます。休みの日も登録するなら、その人の表を別のシートにして1行目に見出しを付けるか、標準テンプレートにしてください。ご提供の勤務表の形（名前の行の下に日付）なら、ずっと休みの人も休みとして読みます）
- 名前の行の無い表で、題名の言葉（地名など）が名前に見えることがあります（所属・部署・店舗などの項目名と、名簿にある名前を優先する仕組みで軽くしています。確認画面で「名簿：◯◯」になっていることを確かめてください）
- 3区間以上の勤務を書き出すと「開始・終了・休憩の合計」になります（取り込み直しても時間・深夜の時間は同じ）
- 停止中で記録の無い人は、在籍期間の中でも月額をかけません（v105と同じ）。月の途中でアポ報酬が変わった月は、損益分岐の粗利に月末の金額を使います
- 報酬の改定で、時給の人に「月額」を入れても効きません（月額固定に変えるときは報酬マスタの支払い方法を変えます）
- 古い形式の .xls と、DecompressionStream の無い古いブラウザ（Safari 16.3 以前など）は SheetJS（ネット）で読みます
- 社会保険料率の改定は画面から入れられません（報酬マスタの月額での入力は可）
- 損益分岐は標準アポ単価で評価します（案件ごとの単価の違いは、実績の売上に反映）

### 先にお伝えすること

- **アポの実際の表は、管理者の画面で貼り付けて取り込んでください。** 会社名・電話番号などはお客様の情報のため、プログラム（GitHub）には入れていません。いただいた添付ファイル4つ（48件）で、全件が正しく読めることを確かめてあります。本文に貼っていただいた分も、同じ形なのでそのまま読めます（行がつながっている所も、1件ずつ分けます）。
- **取り込んだアポは、報酬の計算に入れません。** 表に「いつ取ったアポか（取得日）」が無いためです。アポインターごとのアポの一覧・成果報酬の案件には入ります。アポイント台帳（人が見る台帳）と経営管理システムにも書きません（台帳から来た表のため）。
- **成果報酬の案件は、はじめは NKT・グルメ杵屋・RIG です。** 管理者の画面「🗂 案件の設定」で変えられます。これまでの NKT などのアポは「検討中・次の確認が未定」で入ります。担当のアポインターが予定を入れるか、終わった案件を「見送り」「成約」にしてください。以前の方（園田さん・堀内さんなど）のアポは担当がいないので、管理者の画面でまとめて担当を決められます。
- **アポ報告メールは、システムから a.kusunoki@sukimagroup.jp へ送ります**（件名・内容はこれまでと同じ形）。アポインターのメールアプリは開かなくなります。アプリが新しい設定を受け取るまで（v118 を開いて同期するまで）は、これまでどおりメールアプリで送ります。2通届くことはありません。管理者の画面「⚙️ v118 の設定」で、これまでのやり方に戻せます。
- **外国人の採用の質問は、「案件の設定」で「出さない」にした案件では出しません。** はじめは **CTF**（別名：CTF GROUP・ZERO SALES など）を「出さない」にしてあります。アプリの案件名が違うときは、別名を足してください。設定の無い案件は、これまでどおり出します。
- **お断りの先を「もう一巡」に入れるまでの日数は、はじめは 0（これまでどおり、すぐ入れる）です。** よく使われるのは 90〜180日です（⑶）。
- **新しく作るシート**：「案件の設定」「成果報酬の案件」「成果報酬の履歴」（メインのスプレッドシート）。「アポイント」シートの右に「ヒアリング」列を足します。
- **新しい許可（承認）は求められません**（v117 までと同じ Apps Script のサービスだけを使います）。
- **GAS のデプロイは、GAS の持ち主のアカウント（テレアポ事業部データ格納アカ）で行ってください。** こちらではデプロイしていません。**順番は、GAS が先・GitHub が後です。** デプロイのあと `v112SetupCheck` を実行すると、「案件の設定」シートを作り、v118 の自己点検の結果をログに出します（⑯〜⑱。実行しなくても、はじめの内容で動き、管理者の画面で保存したときにシートができます）。
- **公開している `gas-code.txt` は、ID を伏せてあります**（v117 と同じ2か所：`REC_AUTOSAVE_FOLDER_ID_HERE`・`APPO_LEDGER_SHEET_ID_HERE`）。Apps Script に保存した「コード.gs」には、いまの本番と同じ ID が入っています。
- 確認は、模擬のサーバーと実ブラウザ（Chrome・Galaxy A25 相当の画面・PC）で行いました。**管理者のログインが要る操作と、アポインターとしてのログインは、本番では行っていません**（下の「未検証」）。

## v118 で変えたこと

### ⑴ 実際のアポの取り込み（条件１・管理者）

管理者の画面の **「📥 実際のアポの取り込み（v118）」** で行います。

1. スプレッドシートで行を選んでコピーし、貼り付けます（.txt・.tsv・.csv のファイルでも可。Shift_JIS の CSV も読めます）。
2. **「🔎 読み取って確かめる」**：入る行・重複・似ている行・読めない行と、案件名・取得者のそろえ方を出します（まだ書きません）。
3. **「✓ 取り込む」**：新しい行だけを「アポイント」シートに足します。

| 読み取り | 内容 |
|---|---|
| 表の形 | 案件名｜〇｜〇｜（1 など）｜取得者｜商談日（3/10）｜時間（14:00）｜会社名｜電話｜担当者｜メール｜住所｜メモ｜（そのほか） |
| 1件の見分け方 | 「商談日」と「時間」が並んだ所を目印にします。セルの中の改行（引用符で囲まれたセル）はそのまま。**行がつながって改行が抜けていても、1件ずつ分けます**（つながった前の行の続きは、前の行の「そのほか」へ） |
| 時間 | 14:00・10：00・1300・13時・13時半 |
| 年 | 表に無いため、今日から見て 300日前〜65日後に入る年にします（3/3〜12/7 → 2026年）。画面で年を選ぶこともできます |
| 案件名 | 「案件の設定」の別名でそろえます（エヌケーティー・ＮＫＴ・(株)エヌケーティー → NKT／(株)グルメ杵屋 → グルメ杵屋／RIG協同組合 → RIG）。全角英数・空白もそろえます |
| 会社名 | 全角英数 → 半角、余分な空白、（株）㈱ → 株式会社 など。**同じ会社（法人格・空白・全角の違いだけ）は、先に入っている書き方にそろえます** |
| 取得者 | 名簿の人は正式な名前と PIN（柏木 → 柏木幸代・091）。以前の方（園田・堀内など）は名前だけ（PIN なし） |
| 担当者の欄 | 「施設長　坂上様（男）」→ 役職「施設長」・担当者「坂上様」・性別「男」 |
| 電話・メール | 全角数字・空白をそろえる。メールが2つあれば両方、「無し」は空 |
| 印・メモ | 〇〇1 などの印・メモ・そのほかの列は「引き継ぎメモ」に残します |

| 判定 | 内容 |
|---|---|
| 新しい | 取り込みます |
| 重複 | 同じ商談日で、電話番号か会社名が同じアポが、すでにある（アプリからの報告・前の取り込み）。貼り付けの中の重複も |
| 似ている | 同じ会社（または電話番号）のアポが、商談日の前後45日にある（日時の変更で別の日になっているかもしれない）。**「入れる」に印を付けたものだけ** 取り込みます |
| 読めない | 商談日が無い・会社名も担当者も無い |

取り込んだ行は、アポID が「I＋12桁」、「台帳」列が「取込 2026-11-26」、登録日（取得日）は空です。もう一度同じ表を取り込んでも増えません。**取り込んだアポは、アポインターのアポの一覧では商談日の位置に並びます**（いちばん上に来ない）。

### ⑵ 成果報酬の案件（条件１１）

「案件の設定」で **成果報酬** にした案件（はじめは NKT・グルメ杵屋・RIG）のアポは、自動で「成果報酬の案件」になります（アプリからの報告・取り込み・管理者が案件の設定を変えたとき）。キャンセルしたアポは入れません。

| 段階 | 意味 |
|---|---|
| 商談前 | 商談の日時より前。**商談の3日後の 10:00 に「商談の結果を確かめる」予定** を自動で入れます |
| 検討中 | 商談のあと、先方が検討している（商談の日時を過ぎたら、自動で検討中として扱います） |
| 契約書の送付 | 契約書を送った・回収待ち |
| 成約（契約書回収） | 契約書を回収した（完了） |
| 時期待ち | 「年明けに」「12月まで不在」など、時期を待つ |
| 見送り | 契約しない（完了） |
| アポ取消 | アポがキャンセルされ、連絡もしていない（完了・表示だけ） |

**アポインター（担当）**

- ホームに **「📇 成果報酬の案件（契約書の回収まで）」**：次の確認の日時がきた・過ぎた案件（⏰）と、次の確認が未定の数（📌）。
- **📞 電話番号** を押すと発信し、記録の入力を開いておきます（電話から戻ったらすぐ書ける）。
- **📝 記録する**：どうでしたか（話せた・不在・メール・先方から・メモ）／話した内容／段階／**次の確認の電話の日時**（明日・3日後・1週間後・2週間後・1か月後・年明け のボタンつき）／次にすること。
- 「すべて」から、要対応・未定・追っている・成約・見送り の一覧と、案件ごとの履歴・アポの内容（引き継ぎメモ）を見られます。

**管理者**（「📇 成果報酬の案件」）

- **歩留まりの表**：案件ごとに アポ → 商談済み → 契約書の送付 → 成約、時期待ち・見送り・アポ取消・要対応・未定・**成約率**（成約 ÷ 商談済み）。
- 担当のいない案件（以前の方のアポなど）を、まとめて担当に割り当てる（本人のアプリにお知らせ）。
- 案件ごとに、段階・次の確認・次にすること・担当・メモ・記録を直す。
- **これまでの履歴を入れる**：「11/24 契約書回収の件 RIGの○○様は、…　グルメ杵屋の○○様は、年明けてから」のような報告の文を貼り付けると、日付・案件・先方の名前（○○様・さま・さん）で分けて、案件を探します（名前の頭が同じ案件が1つだけなら自動で選びます。候補が複数のときは選んでください）。「年明け」→ 1/6、「25日以降」→ 次の25日、「12月まで」→ 1/5 を次の確認の目安に入れ、「時期待ち」にします。同じ履歴を2回入れても増えません。

シート：「成果報酬の案件」（1案件1行：案件ID・アポID・案件名・法人名・担当者・電話・メール・商談日時・担当・段階・次の確認・次にすること・最後の連絡・最後の記録・メモ）と「成果報酬の履歴」（記録1件1行）。

### ⑷ 自動修正

| 見つけたこと | 直したこと |
|---|---|
| 「外国人の採用も候補になるか？」が、CTF（営業代行）などすべての案件のアポ報告に出て、答えないと「条件が未確認のアポ」として数えられていた | 案件の設定で「出さない」にした案件では、出さない・数えない（はじめは CTF を「出さない」） |
| アポ報告メールが、アポインターのスマホ・パソコンのメールアプリ頼みだった（メールアプリの無いパソコン・メールアドレスの無い人は、報告メールが届かない） | システムから送る（宛先・件名・内容はこれまでと同じ。ヒアリングの答えも入れる） |
| パソコン・Zoom Phone で発信する人にも、ホームの「🎙 通話録音の自動保存」と、出勤のときの「録音の自動保存が未設定です」が出ていた | スマホ（Android）だけに出す（パソコンでフォルダをつないである人には、これまでどおり出す） |
| 録音フォルダの手順が「内部ストレージ → Recordings → Call」だったが、Galaxy A25 のフォルダを選ぶ画面のいちばん上は「Galaxy A25 5G」で、そこでは「このフォルダは使用できません」と出る | 手順を「Galaxy A25 5G → Recordings → Call」にし、「このフォルダは使用できません」と出ても進めば使えること、「最近」が出たときの開き方を書いた |
| 架電の集計（fetch_call_summary）の通話時間：「1:23」（1分23秒）がスプレッドシートで時刻（1時23分）に変わると、秒数がずれる | 「通話秒」の列を優先する。時刻になったものも「分:秒」として読む。新しい行は文字で保存する |
| 取り込んだアポ（取得日なし）が、アポの一覧のいちばん上に並ぶ | 商談日の位置に並べる |
| 自己点検の例に、実在の会社名・電話番号が入っていた | 架空の名前・番号に変えた |

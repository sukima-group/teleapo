# 川嶋メソッド テレアポ業務管理システム v104（中村・田中・片山さんの取込・書き込みを修正）

スキマグループ合同会社｜2026年9月28日

## 🆕 v104：取り込めない・書き込めない原因を4つ特定して修正

### 原因① 元シートへ「書き込めない」のに「反映しました」と表示していた（最重要）
元スプレッドシートに **書き込み先の列（日付・時刻・名前・結果）が無い**と、
プログラムは**何も書かずに次へ進み、それでも「反映 ◯件」と報告**していました。
新メンバーのリストは会社名・電話番号だけの表が多く、まさにこの状態でした。

**修正**：書き込み先の列が無ければ、**元シートの右端に「架電者・架電日・架電時刻・架電結果」の4列を自動で追加**してから書き込みます。実際に書き換えたセル数も記録します。

### 原因② 「設定」ボタンが古い処理のままだった
v96で作った「1手ずつ診断する設定」は、**置換が途中で止まっていてボタンに結線されていませんでした**。
画面上は新しく見えても、裏では古い処理が動いていました。**今回、正しく結線し直しました。**

### 原因③ 設定の保存時に「どのタブか（gid）」を保存していなかった
タブ名が変わったり同名があると、取込・反映で**「シートが見つかりません」**になります。gid も保存するよう修正しました。

### 原因④ PINの先頭ゼロが消える
スプレッドシートは「091」を**数値の91**に変えることがあり、設定と名簿が照合できなくなります。**91も091として扱う**よう修正し、保存時は文字列で保存します。

---

### 新しい「設定」ボタン：1回で取込まで完了
未設定の方の行の黄色い欄にURLを貼って **[設定]** を押すと、次を**自動で一気に**行います。

```
⚙️ 田中久美子 さんの連携
　✓ 名簿に登録されているか   田中久美子（110）
　✓ URLの読み取り           スプレッドシートID を確認
　✓ スプレッドシートを開く    田中さん架電リスト
　✓ 使うタブ                「田中リスト」
　✓ 見出し行                3行目               ← タイトル行があっても自動で見つける
　✓ 列の特定                会社名=1列／電話=2列
　✓ 書き込み先の列          元シートに追加しました：架電者・架電日・架電時刻・架電結果
　✓ 設定の保存              保存しました
　✓ 保存の確認              読み直しOK
　✓ 取り込み                取り込み 120件
　✓ 反映の試算              確認のみ／反映予定 0件
```
**× が出たら、その行の説明がそのまま原因**です（例：「開けません。hr.ashikaga@gmail.com に編集者で共有してください」）。

**設定済みでも前回エラーだった方**には、同じURL欄が再表示されるので、何度でもやり直せます。

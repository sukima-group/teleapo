# 川嶋メソッド テレアポ業務管理システム v72（経営管理システムをドライブ上へ）

スキマグループ合同会社｜Galaxy A25 5G ＋ ワイモバイルSIM

## 🆕 v72：経営管理システムが Googleドライブ の中で動きます

これまで経営管理システムは **経営PCでPythonを動かしてExcelを作る** 方式でした。v72では、ご指定のドライブフォルダの中に**スプレッドシート形式で自動生成**します。

**パソコンもPythonもExcelも不要。スマホのブラウザからも見られます。**

### できあがる構成
```
（ご指定のフォルダ）
└ 経営管理システム/
   ├ スキマグループ_経営管理システム   ← これを開く（スプレッドシート）
   ├ 01_月次レポート/ 2026-08/ …_2026-08   ← 月ごとの控え（自動保存）
   ├ 02_バックアップ/
   └ 03_エクスポート/ daily.csv        ← Looker Studio等に直結できるCSV
```

### スプレッドシートの中身（7シート）
| シート | 内容 |
|---|---|
| **ダッシュボード** | 本日／今月の 架電・接続・アポ・実働h・アポ率・接続率、品質チェック件数、録音カバー率、**アポインター別ランキング（アポ数順15名）** |
| 日次集計 | 日付×担当者の 実働h・架電・接続・アポ・**接続率・アポ率・架電/h** |
| アポインター別 | 稼働日数・実働h計・架電・接続・アポ・各種率・**アポ/日** |
| 月次推移 | 月ごとの合計と平均（前月比較ができます） |
| アポ一覧 | 商談日・時間・案件名・法人名・報告者 |
| 品質レポート | 打刻漏れ／名簿外の名前／アポ件数の差異／稼働空転／シフト乖離／アポ率急落 |
| 録音カバレッジ | 日付×担当者の 架電・録音・カバー率 |

**ダッシュボードは数式で組んである**ため、開くたびに最新の計算結果が表示されます。

### ⏱ 自動更新
管理画面から **「毎日20時」または「6時間ごと」をワンタップ**で設定できます（GASエディタ不要）。設定後は放置で最新化されます。

## ✅ 検証（50/50 合格）
- **集計ロジック 37項目**：作成先フォルダの解釈（URL／ID／既定値）・フォルダ名3種／日次行（接続率40%・アポ率4%・架電/h 8.3・「推定」表示・実働なしは空欄）／アポインター別（アポ数順・稼働3日・実働17.0h・アポ率4.7%・架電/h 8.8・アポ/日 2.33）／月次推移（古い順・稼働日数・8月のアポ率5.0%）／空データでも落ちない・架電0で割り算エラーにならない
- **ダッシュボード数式 13項目**：本日（架電70・接続25・アポ4・実働11h・アポ率5.7%・接続率35.7%）／今月（架電120・アポ率5.0%・接続率37.5%）／**翌月分が今月に混ざらない**ことを実データで照合
- **数式の構文**：生成される15本すべてで括弧・引用符の整合を確認

## ⚠️ デプロイと使い方

1. **GAS**：「コード.gs」全消去 → `gas-code.txt` 貼付 → 保存 → **新しいバージョン**でデプロイ
2. 初回実行時の **ドライブへのアクセス承認**を許可
3. **GitHub**：8ファイル Upload → Commit ／ **全端末**：キャッシュクリア → ホーム画面に再追加

### 作成手順
1. ログイン画面に「**v72**」
2. 管理者 → **「📊 経営管理システム（Googleドライブ上）」**
3. 作成先フォルダは**空欄のままでOK**（ご指定のフォルダが既定値です）。別の場所に作る場合のみURLを貼ってください
4. **「📊 経営管理システムを作成／更新する」** を押す（1分ほど）
5. **「📈 経営管理システムを開く」** でスプレッドシートが開きます
6. **「⏱ 自動更新」→ 毎日20時** をON

> 💡 スプレッドシートを開いたら、右上の☆（スター）を付けるか、スマホのGoogleドライブアプリでショートカットを作っておくと、次回からすぐ開けます。

## 🆕 v57：架電位置を「サーバーにも」保存。端末側が消えても続きから

### v56までが不十分だった理由
v53〜v56では架電位置を**端末の中だけ**に保存していました。
ところが Android は空き容量が減ると、**PWAの保存領域をアプリごと丸ごと消してしまう**ことがあります。
こうなると位置もログイン状態も同時に失われ、**先頭の会社に戻ってしまいます**。
端末内をいくら二重化しても、消えるときは両方まとめて消えるため、これが残っていた原因です。

### 解決：位置の控えをサーバー（スプレッドシート）に持つ
新しく **「架電位置」シート** を用意し、次の内容を1人1行で保存します。

| PIN | 名前 | 端末ID | 行番号 | 会社名 | 電話番号 | 元行 | 更新日時 |
|---|---|---|---|---|---|---|---|

- 位置が変わるたびに（30秒に1回まで）自動送信。**画面が消える瞬間は必ず送信**します
- 開き直したとき、端末内の記録が失われていても、**サーバーの控えから同じ会社に戻ります**
- **端末IDが一致するときだけ復元**します（ご要望どおり、同じ端末のときのみ）
- 端末内により新しい記録があれば、そちらを優先します（通信が無くても動きます）

### これで3重の備えになりました
| 保存先 | 役割 |
|---|---|
| ① 端末内（主） | いつでも即座に復元。通信不要 |
| ② 端末内（予備） | 主の保存が失敗したときの受け皿 |
| ③ **サーバー（新規）** | **端末の保存領域ごと消えても復元できる最後の砦** |

### 継続している機能（v53〜v56）
- 復元の手がかり：**元行 → 電話番号 → 会社名 → 何件目 → 未架電の最初**
- ログイン状態を16時間保持（同じ端末のときのみ・操作で延長）
- 入力途中のチェック・メモ・文字起こしの復元
- **🔆 画面を消さない**（既定ON）

## ✅ 検証（18/18 合格＋既存回帰）
本番コードから抽出して検証：**端末内が空でもサーバー位置を採用して同じ会社に戻る（先頭に戻らない）**／**別端末で保存された位置・端末IDが空の位置は使わない**／端末内が新しければサーバーを採用しない・古ければ採用・同時刻は端末内優先／中身が無い位置やnullでも落ちない／復元の優先順位（元行→電話→会社名→番号、範囲外は不採用）／端末IDが無い過去データの受け入れ。v45〜v56の全スイートも再実行して合格。

### 確認手順（藤田さんの端末で）
1. ログイン画面に「**v57**」→ PIN 101 と暗証番号でログイン
2. 数件架電し、通話画面の **「📍 ◯ / ◯ 件目」** が進むことを確認
3. スプレッドシートの **「架電位置」シート**に、藤田さんの行（会社名・端末ID）が入ることを確認
4. **電源ボタンで画面を消して数分放置** → アプリを開く → **さきほどの会社から再開**すること
5. （強い確認）Chromeの設定でこのサイトのデータを削除 → アプリを開く → PIN と暗証番号を入れると、**サーバーの控えから同じ会社に戻る**こと

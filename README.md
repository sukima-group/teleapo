## 🆕 v63：「🔄 再同期」を押したら必ず1件目から

### 原因
リストの中身は正しく取り込めていましたが、**架電位置だけが前回の続き（23件目）に復元**されていました。
そのため「リスト画面ではスプレッドシートどおりの順番なのに、発信画面は 23/482 から始まる」という状態になっていました。

もうひとつ、**リストの変化を「件数・先頭・末尾の会社名」だけで判定**していたため、
**途中の行だけを差し替えた場合に「変わっていない」と誤判定**し、位置がそのまま残っていました。

### 修正1：再同期は「取り直す操作」として扱う
**「🔄 再同期」ボタンを押したときは、必ずリストの1件目から開始**します。

- ホーム画面の「🔄 再同期」・集計画面の「🔄 サーバーから再同期」の**どちらでも**同じ動作です
- 保存していた位置（端末内・予備・サーバーの控え）とスキップ状態も解除します
- 「📋 リストを読み込み直しました（482件・1件目から開始します）」と件数つきで表示します
- **画面がスリープしただけの復帰では、これまでどおり続きから再開**します（再同期を押したときだけ先頭に戻ります）

### 修正2：リストの変化を「中身全体」で判定
件数・先頭・末尾だけでなく、**全行の会社名と電話番号から署名を作って比較**するようにしました。

- 途中の1行だけ差し替えた場合も**確実に検出**して1件目から開始します
- 電話番号の修正だけ、並び順の入れ替えだけでも検出します
- 変更が無いときは従来どおり続きから再開します（余計なリセットは起きません）

### 追加：「⏮ 1件目へ」ボタン
発信画面の位置表示（📍 23 / 482 件目）の横に、**いつでも先頭へ戻れるボタン**を追加しました。
再同期を待たずに、その場でリストの1件目に戻れます（NG番号やスキップ済みは飛ばして先頭の対象へ移動します）。

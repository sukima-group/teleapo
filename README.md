# 川嶋メソッド テレアポ業務管理システム v97（画面が更新されない問題への対処）

スキマグループ合同会社

## 🆕 v97：同じ画面が続く本当の理由

### ご報告の画面から分かったこと
いただいた画面はこうなっています。
```
小澤幸枝 105    未設定    —    設定
```
**ボタンが「設定」1つだけ**です。

しかし **v94以降は、全員に「設定」「取込」「反映」の3つ**が表示される作りになっています。
つまり——**新しいコードが端末に届いていません。** 古い画面のまま操作されていた可能性が高いです。

これでは、私がいくら中身を直しても状況は変わりません。**まず「新しい版が届く」ことを確実にする**必要がありました。

### 解決①：いま動いている版が必ず見えます
**ログイン画面**の下部と、**管理画面の一番上**に版を表示します。
```
アプリ版 v97    画面が古いと感じたら右のボタンを押してください   [🔄 更新]
```
**ここが v97 になっていなければ、コードが届いていません。**一目で判断できます。

### 解決②：ワンタップで強制更新できます
**[🔄 更新]** を押すと、次を自動で行います。
1. 保存されたキャッシュをすべて削除
2. Service Worker の登録を解除
3. 時刻付きのURLで読み込み直し（キャッシュを完全に迂回）

保存済みのデータ（リスト・履歴・設定）は消えません。共有された録音も残します。

### 解決③：ログイン前でも更新できます
ログイン画面にも更新ボタンを置いたので、**PINを入れる前に最新化**できます。

## ⚠️ 導入手順（順番が大切です）

1. **GitHub**：8ファイルを Upload → **Commit**
   ※ ファイル名が同じでも「Commit changes」まで押してください

### ★ まずこれをご確認ください
アプリを開いて、**ログイン画面の下に「版 v97」と出ていますか？**

- **v97 と出ている** → コードは届いています。管理者でログインし、連携画面で3ボタンをご確認ください
- **v96以前と出ている／何も出ていない** → **[🔄 最新の状態に更新] を押してください**
- 押しても変わらない場合 → GitHubの Commit が完了しているかご確認ください

版が v97 になれば、**未設定の方の行にURL入力欄が出て、「設定」「取込」「反映」の3ボタンが並びます。**

# 川嶋メソッド テレアポ業務管理システム v99（名簿変更の完全反映・KPIの経営連携）

スキマグループ合同会社｜2026年9月

## 🆕 v99：v98が60点だった理由

v98は**名簿の文字を4名に書き換えただけ**でした。実際の運用では、次が残っていました。

| 残っていた問題 | v99の解決 |
|---|---|
| 退職者のPINが**連携設定・録音設定・KPI目標に残る** | 🧹 **① 退職者の設定を片付ける** で全シートから削除（履歴シートは「旧_」で退避） |
| 新メンバーの**シート・録音フォルダ・KPI目標が手作業** | 🆕 **② 新メンバーの初期設定** で3つを一括作成・共有 |
| KPIが**経営管理システムに一切流れない** | 📤 **経営システムへ反映** で「KPI_アポインター別」シートに書き込み。①設定の目標（R_CONN／R_MTG）も同期 |
| 低調が続いても**誰も気づかない** | ⚠️ **3日連続で架電が目標の6割未満**なら画面と夜間メールで通知 |

### 名簿変更は3手順で完了します
```
👥 名簿変更の反映（4名体制）
　[ 🧹 ① 退職者の設定を片付ける ]
　　✅ 完了：対象PIN 091・098・105・108
　　　外部連携設定：1行　録音設定：4行
　　　シート退避：柏木・竹之内・小澤・榮
　[ 🆕 ② 新メンバーの初期設定（シート・KPI・録音フォルダ）]
　　✓ 田中久美子：シート○ KPI○ 録音○（共有:tanaka.sukimagroup@gmail.com）
　　✓ 中村花林：シート○ KPI○ 録音○
　　✓ 片山佳代：シート○ KPI○ 録音○
　[ 🔗 ③ 経営システムの名簿を今の4名に合わせる ]
```
**履歴は消えません。**退職者の架電履歴シートは「旧_柏木」のように名前を変えて残します。

### KPIが経営管理システムに入ります
「📤 経営システムへ反映」を押すと、経営管理システムに **「KPI_アポインター別」** シートができ、
担当者ごとの **実績（架電/日・接続率・アポ率・アポ/日・実働・架電/h）／目標／総合達成率／評価** が並びます。
第5期版では **①設定の接続率目標・商談率目標** にも全員の目標平均を反映します。
**夜間処理にも組み込み**、毎晩自動で更新されます（7手順目）。

### 低調アラート
**直近3日すべてで架電が目標の60%未満**の担当者を検出し、画面と夜間メールで知らせます。
「2日だけ」や「ちょうど60%」は通知しません（過敏にならないよう境界を検証済み）。

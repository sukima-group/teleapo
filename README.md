## 🆕 v46：新メンバー3名を「確実に使える」状態へ（60点→100点の根本修正）

### 60点の原因（実機で新PINが機能しなかった理由）
新メンバーのPIN・名前・メールは v45 で登録済みでしたが、**サーバー（GAS）のリスト取得処理が「本人のリストシートが存在しないとエラーを返す」仕様**のままでした。藤田・本郷・小澤の各シート（「藤田」「本郷」「小澤」）は初回時点で存在しないため、**初回ログインの同期がエラーになり、使えない状態**でした。これが根本原因です。

### v46 の修正と保証
1. **doGet（リスト取得）を修正**：シートが無い場合は**その場で自動作成し、「リスト未登録」として正常応答**（エラーにしない）。新メンバーは初回ログインからスムーズに入れて、「リスト読込」でアップロードすればすぐ架電開始できます
2. **🩺 セットアップ診断（管理者・新設）**：ボタン1つで**全10名の利用可否を一括点検**
   - **リストシート**：有無と件数（無ければ**自動作成**して🆕表示）
   - **暗証番号**：設定済み／未設定（未設定は本人の初回ログインで設定）
   - **本人メール**：登録有無（✉＝藤田・本郷・小澤）
   - **📧 テストメール送信**：登録3名のGmailへテスト送信し、通知経路が生きていることを実証（本日の送信残り枠も表示）
3. 点検・テスト送信は**監査ログに記録**されます

### 継続（v45で実装済み・そのまま有効）
- **PIN 101 藤田直美／103 本郷真弓／105 小澤幸枝**（全帳票・全パネルに自動反映）
- **本人宛メール3種**：シフト承認/差戻し結果・重要お知らせ一斉配信・退勤時の実績控え（登録3名のGmailへ）

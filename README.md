## 🆕 v89：2種類の様式から選んで自動生成できます

### 足りなかったこと
v77で内蔵したのは**第5期版（41シート）の設計データだけ**でした。
ご指定の **①設定・マスタ 〜 ⑬同期・品質レポート（21シート版）** は生成できませんでした。

### 解決：両方を内蔵し、ボタンで選べるようにしました
```
作成する様式を選んでください
[ ✅ 標準版          ] [ 第5期版           ]
  ①設定・マスタ〜        ①設定〜㉚前期比較
  ⑬同期・品質レポート     （41シート）
  （21シート）
```

**標準版（21シート）に含まれるシート**
目次／**①設定・マスタ／②ダッシュボード／③案件別売上／④入金回収管理／⑤アポインター管理／⑥テレアポKPI／⑦月次損益予実／⑧顧客分析／⑨経営計画サマリー／⑩報酬マスタ・月次コスト／⑪日次アポ取得ログ／⑫アポ納品・日程管理／⑬同期・品質レポート**／報酬エンジン／資金繰り表／損益分岐点／パイプライン／収益分析／コホート分析／KPIツリー予測

**ご指定の13シートはすべて含まれています。**
ファイル名が異なる（標準版＝`スキマグループ_経営管理システム`／第5期版＝`スキマグループ_経営管理_第5期`）ので、両方を並べて使うこともできます。

### 検証中に見つけた重大な欠陥を修正
標準版の⑪日次アポ取得ログは、**5行目に集計行（本日のアポ／今月 架電計…）があり、6行目が見出し**という構造でした。
従来の判定では**5行目を見出しと誤検出**し、**データが投入できませんでした**。

**見出しの判定を厳密化**しました。
- 「日付」「担当」「架電数」が**それぞれ別のセルに単独で**入っている行だけを見出しとみなす
- 長い説明文のセル・数式のセルは見出しにしない

あわせて、**実働h の列が検出できていなかった不具合**も修正しました。

### GASファイルを3つに分割しました
設計データを2つ内蔵すると1ファイルが850KBを超えるため、分割しました。

## ⚠️ 導入手順（GASは3ファイルになります）

1. **GAS**：「コード.gs」を全消去 → `gas-code.txt` を貼付
2. 左の「ファイル」の **＋ → スクリプト** → 名前を **`spec-std`** → `spec-std.gs.txt` の中身を貼付
3. 同様に **＋ → スクリプト** → 名前を **`spec-k5`** → `spec-k5.gs.txt` の中身を貼付
4. 保存 → 「デプロイを管理」→ **新しいバージョン** → デプロイ
5. **GitHub**：8ファイル Upload → Commit ／ **全端末**：キャッシュクリア → 再追加

### 作成手順
1. 管理者 →「📊 経営管理システム（Googleドライブ上）」
2. **様式を選ぶ**（既定は標準版21シート）
3. **「📊 作成／更新する」** → 「🏗 新規作成（21シート／名前付き範囲7/7）」と表示されれば成功
4. **「📈 開く」** → ⑪日次アポ取得ログにデータが入っていることを確認
5. 入っていない場合は **「🩺 反映されない原因を調べる」**

## 🆕 v49：ズレを「照合で頑張る」から「そもそも起きない」へ

### v48が不十分だった理由
v48は「架電結果 → 元シートへ書き戻す」半分しか作れておらず、**元シートから架電リストを取り込む工程が無い**ままでした。
リストは手作業でコピーする前提だったため、**並び順の一致が保証されず**、会社名の表記照合に頼らざるを得ませんでした。これがズレの根本原因です。

### v49の解決：往復をつなぐ「元行（もとぎょう）」
**元シート → 架電リスト → 架電 → 元シート** を1本の流れにし、各行に**元スプレッドシートの行番号**を持たせました。

| 工程 | v49の動き |
|---|---|
| ① 取り込み | 元シートから会社名・電話・担当者・住所を**並び順そのまま**取り込み、各行に **「元行」** を記録 |
| ② 架電 | 架電結果に**その「元行」が自動で付く**（アポインターの操作は一切増えません） |
| ③ 書き戻し | **元行の番号で直接その行に書き込む**（会社名の照合を経由しない＝**ズレは原理的に発生しません**） |

**同名の別会社が並んでいても取り違えません。** 表記ゆらぎの照合（v48の3段構え）は、元行が無い過去データ用の**フォールバック**として残してあります。

### あわせて追加した機能
- **🔎 見出しから列を自動検出**：URLとシート名を入れてボタンを押すだけで、会社名・電話・担当者・住所・日付・時刻・名前・結果の列を自動で埋めます（「通話時間」を「時刻」と誤検出しない等の除外条件つき）
- **📥 取り込みボタン**（全員／個人）：管理者ビューから元シート→架電リストの取り込みを実行
- 取り込み時に**会社名が空の行は自動スキップ**（元シートの空行・小計行を持ち込みません）

## 運用の流れ（管理者）

1. 「🔗 元スプレッドシート連携」→ **「設定」** → URL・シート名を入力 → **「🔎 見出しから列を自動検出」** → 内容を確認して **保存**
2. **「📥 元シートから架電リストを取り込む」** → 藤田・小澤などのシートに、元シートの並び順のままリストが入ります
3. アポインターがアプリで「リスト読込」→ 架電（**元行は自動で付きます**）
4. **「🔍 確認のみ」** で反映件数を点検 → **「🔄 全員を反映」**（または各人の「反映」）
5. 元スプレッドシートの **日付・時刻・名前・結果** が、正しい行に入ります

> ⚠️ **必須**：元スプレッドシートを **hr.ashikaga@gmail.com に編集権限で共有**してください。
> 💡 **自動化**：GASで `autoSyncExternal` を時間主導トリガー（1時間おき等）に設定すると、書き戻しが全自動になります。

スキマグループ合同会社

## 🆕 v75：お使いの「経営管理_第5期」がドライブ上で動きます

### v74までが不十分だった理由
v74までは、**Pythonが生成した21シートのひな形**を前提にしていました。
実際にお使いなのは **41シートの「スキマグループ_経営管理_第5期」**（②ダッシュボード／③案件売上／④回収管理／㉒与信・督促／⑤アポインター／⑥テレアポKPI／㉔個人スコアカード／⑦月次損益／㉗差異分析／㉘区分別損益／㉑ローリング予測／㉚前期比較／⑩資金繰り／⑳13週資金予測／⑫パイプライン／⑮報酬エンジン／⑯コホート／㉕Whatifシミュレータ ほか）で、**シート名も投入先も列の並びも違いました**。これでは動きません。

### v75の解決：実物のレイアウトに合わせました
| 項目 | 第5期の実際 | v75の対応 |
|---|---|---|
| 投入先 | **⑰日次活動ログ** | シート名を自動判別 |
| 見出し行 | **3行目** | 「日付」「アポインター」を含む行を自動検出 |
| データ開始 | **4行目** | 見出しの次行から |
| 列の並び | 日付／アポインター／架電数／接続数／アポ数／商談数／成約数／メモ／集計月 | **見出しから列位置を自動判定** |
| 名簿 | **①設定 の アポインターマスタ** | 読み取って名前を突合 |

### 高度化した点
- **名前の表記ゆれを吸収**：システム側「堀内真紀子」↔ 名簿「堀内」、「藪内亜希」↔「藪内亜紀」、「市川玲佳」↔「市川玲佳（役員）」を同一人物として突合します
- **手入力の行を残します**：メモ欄が「自動連携」で始まる行だけを差し替えるため、**手で入れた日報は消えません**
- **名簿にない担当者を報告**：「⚠ 名簿にない担当者：榮智子(3件)」と表示し、①設定への追加を促します
- **商談数・成約数は触りません**：架電システムが持たない項目なので、手入力を尊重します

1. **GAS**：「コード.gs」全消去 → `gas-code.txt` 貼付 → 保存 → **新しいバージョン**でデプロイ
2. **GitHub**：8ファイル Upload → Commit ／ **全端末**：キャッシュクリア → 再追加
3. **`スキマグループ_経営管理_第5期.xlsx` を、ドライブの「経営管理システム」フォルダへアップロード**
4. 管理者 → 「📊 経営管理システム（Googleドライブ上）」→ **「📊 経営管理システムを設置／更新する」**

スキマグループ合同会社｜Galaxy A25 5G

## 🆕 v83：v82が60点だった技術的な理由

### 検証で見つけた欠陥
v82は録音を**文字列に変換してGASへ送る**方式でした。実際のファイルサイズで計算すると——

| 通話時間 | ファイル | GASへ送るJSON本文 | 結果 |
|---|---|---|---|
| 3分 | 1.4MB | 1.9MB | 送れる |
| 10分 | 4.7MB | 6.2MB | やや不安定 |
| **20分** | **9.4MB** | **12.5MB** | **失敗しやすい** |
| **30分** | **28MB** | **37.3MB** | **ほぼ失敗** |

**長い通話ほど失敗する**——アポが取れた重要な通話ほど落ちる、最悪の性質でした。

### v83の解決：ドライブへ直接送る
```
① 架電システムがGASに「アップロード用の一時URL」を発行してもらう
② 端末からGoogleドライブへ、ファイルをそのまま直接送信（文字列化しない）
③ 完了をGASに通知して記録
```
**文字列に変換しないため肥大せず、サイズの制約が事実上なくなりました**（上限400MBに設定）。
万一この方法が使えない環境でも、**自動で従来方式に切り替えて**送信します。

### あわせて追加した3点
**① 送信済みの記憶** — 同じ録音は二度送りません。**途中で失敗してもやり直せば続きから**送れます（端末側・サーバー側の二重チェック）。

**② 退勤時の自動案内** — 退勤を押した直後に、未送信があれば
「本日の通話録音がまだ送信されていません（架電20件／送信0件）。今すぐ送信しますか？」
と確認し、**そのまま選択画面が開きます**。忘れる余地をなくしました。

**③ 管理者：本日の提出状況** — **「🔎 本日の提出状況を確認」**で、担当者ごとの
**架電件数／送信件数／未提出件数**を一覧表示。未提出が多い順に並ぶので、誰に声をかければよいか一目で分かります。

## ✅ 検証（28/28 合格 ＋ 回帰97項目）
**新機能 28項目**：**20分(9.4MB)・30分(28MB)・100MBの録音が選択できる**こと／400MB超は除外／**従来方式のJSON本文が12.5MB・37.3MBに肥大することを数値で確認**（欠陥の再現）／送信の流れ（一時URL→送信→完了）／保存済みならスキップ／一時URLが取れない場合と送信失敗時の**自動フォールバック**／両方失敗時は失敗として報告／送信済み鍵（名前×サイズ）／**5名それぞれの保存先パス**／未登録PINと画像の拒否／未提出者の洗い出し（架電ゼロは対象外・未提出が多い順・件数の正確さ）。

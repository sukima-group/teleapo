# 川嶋メソッド テレアポ業務管理システム v71（MacroDroid導通チェック）

スキマグループ合同会社｜Galaxy A25 5G ＋ ワイモバイルSIM

## 🆕 v71：MacroDroid の設定を「配って・入れて・確かめる」まで一本化

v70までは「MacroDroidで自動送信できます」と案内するだけで、**本当に動いているかを確かめる術がありませんでした**。設定ミスに気づくのは、録音が集まらないと分かった数日後。ここを埋めました。

### ① 📱 端末セットアップの設定値（管理画面）
「📱 端末セットアップの設定値を見る」で、**全員分の入力値を一覧表示**します。
- **宛先**（全員共通）／**件名に入れる文字**（例：`録音 竹之内優子`）／**送信元アカウント**
- 会社Gmail未登録の方は「（会社Gmail未登録）」と明示（件名の名前で判別されます）

### ② 📡 導通チェック（本命）
各メンバーの行の「📡 導通」を押すと、**直近30分の受信を調べて、動いているかを判定**します。
届いていない場合は**原因まで表示**します。

| 判定 | 表示される原因 |
|---|---|
| ✅ 届いた | 受信したファイル名とサイズを表示 |
| 未着 | マクロがOFF／フォルダ違い／通話録音がOFF |
| 添付が正しくない | 添付ファイルがありません（＝「トリガーとなったファイル」未設定） |
| 〃 | 音声ファイルではありません（＝別フォルダを監視） |
| 〃 | 大きすぎます（25MB超）— サイズも表示 |
| ⚠ 注意 | 会社のGmail以外から届いています（件名の名前で判別しました） |

### ③ 設定カードPDF（端末に添えて配る）
**`録音自動送信_MacroDroid設定カード.pdf`**（A4・2ページ・白黒印刷対応）
- 1ページ目：共通の設定手順6ステップ＋間違えやすい点
- 2ページ目：**11名分の「件名にこう入力」一覧**＋設定後の流れ＋トラブルの見分け方

## ✅ 検証（36/36 合格）
**導通判定 25項目**：成功時のファイル名返却／添付なし・画像・25MB超をそれぞれ原因つきで指摘／未着の判定と時間幅の明示／他人のメールを成功にしない／29分は範囲内・31分は範囲外・窓を60分に広げれば拾う／個人アドレスでも件名の名前で救済し注意を添える／会社Gmail未登録の案内／設定値の生成（件名・フォルダ・宛先・7手順）。
**回帰 11項目**：11名の名簿整合／即時反映の増分／実働計算／録音の判定・日時解釈・番号抽出・紐づけ。

## ⚠️ デプロイ
1. **GAS**：「コード.gs」全消去 → `gas-code.txt` 貼付 → 保存 → **新しいバージョン**でデプロイ
2. **GitHub**：8ファイル Upload → Commit ／ **全端末**：キャッシュクリア → ホーム画面に再追加
3. 設定カードPDFを印刷し、端末に添えて配布

### 確認手順
1. ログイン画面に「**v71**」
2. 管理者 →「🎙 通話録音の管理」→ **「📱 端末セットアップの設定値を見る」**
3. 端末でPDFのとおりマクロを作成 → **1件テスト架電**
4. 数分後、その方の行の **「📡 導通」** を押す → **「✅ 届いた」＋ファイル名**が出れば完成
5. 出ない場合は表示された原因のとおりに直し、もう一度「📡 導通」

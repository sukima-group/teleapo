### これまでの問題
v95まで、私は原因を**推測**してお伝えしていました（共有権限では／GASが古いのでは）。
しかし**実際に何が起きているかを確認する手段が無い**ため、同じ状態が続いていました。

### v96：設定を6手順に分け、どこで止まったかを画面に出します
「設定」を押すと、次を1つずつ実行して**結果をその場に表示**します。

```
🩺 柏木幸代 さんの設定 診断
　✓ ① サーバーに届くか        サーバー版 v96
　✓ ② スプレッドシートを開けるか  2個のタブ： 柏木・集計
　✓ ③ 使うタブの決定          「柏木」を使います
　× ④ 見出しを読めるか        1行目に「会社名」「電話番号」の見出しがありません
　                          ／実際の見出し: 法人名,TEL,住所

　👉 ここを直してください
　　そのタブの1行目に「会社名」「電話番号」という見出しが必要です。
```

**× が付いた手順がそのまま原因**です。応答の中身もそのまま表示するので、推測が不要になります。

### 6つの手順と、それぞれの対処
| 手順 | 失敗したときの原因 |
|---|---|
| ① サーバーに届くか | GASのURLが違う／デプロイされていない |
| ② スプレッドシートを開けるか | **hr.ashikaga@gmail.com への編集者共有がない**／URLが違う／ゴミ箱にある |
| ③ 使うタブの決定 | （自動選択。失敗しません） |
| ④ 見出しを読めるか | **1行目に「会社名」「電話番号」が無い**（実際の見出しも表示します） |
| ⑤ 設定を保存できるか | GASが古い |
| ⑥ 保存されたか確認 | **保存したのに未設定のまま＝GASが古い** |

**⑥まで通れば、その場で「✅ 設定済」になります。**

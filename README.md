# 川嶋メソッド テレアポ業務管理システム v98（「設定・取込・反映」100%動作版）

スキマグループ合同会社

## 🎯 今回のご依頼と進め方

「やっぱり 取込・反映 ができない。100% 設定・取込・反映 の3つができるようにして」

そこで今回は、**推測で直すのをやめて**、次の順で進めました。

1. **事例調査**：システム構築が上手な会社のやり方を確認
   - Google公式：ウェブアプリは**「新しいバージョン」でデプロイするまでコード変更が反映されない**（テストURLと公開URLの違いで嵌まりやすい）
   - Stripe等の一流API設計：**変更は「追加のみ」**で旧クライアントを壊さない／エラーは**機械が読める形＋人が直せる文言**で返す／**全応答に版情報**を含めて新旧を判別可能にする／**契約テスト**で入出力を固定する
2. **仮説→再現**：実物の gas-code.txt と index.html を**Node上で丸ごと動かす契約テスト**を作り、旧v95/v97で不具合を**再現**（＝原因の証明）
3. **根治→検証**：直した v98 を同じテストに通し、**41項目すべて合格**を確認

## 🔎 見つかった原因は「1つではなく4つ」でした（すべて再現テストで証明済み）

| # | 場所 | 症状 | 根本原因 | 証拠（再現テスト） |
|---|---|---|---|---|
| **①** | GAS | 行の**「設定」が必ず失敗**。全員実行・監査・展開も失敗 | 応答ヘルパー `J()` が**関数の中にしか定義されておらず**、doPost の ping／ext_bulk_configure／ext_run_everyone 等が **`ReferenceError: J is not defined`** で即死 | 旧v95で ext_bulk_configure → error「J is not defined」 |
| **②** | アプリ | ①の保険だった**代替手順も、診断④も必ず失敗**（「見出しが見つかりません」） | ext_detect の列情報は応答の `detect` の**中**に入るのに、v94〜v97 は**直下から読んでいた** | 旧v97の extLegacySet に正しい応答を与えても失敗 |
| **③** | GAS | まとめて登録で**画面で選んだタブが無視**される | `ext_bulk_setup` ハンドラが**2つ重複**し、map（タブ指定）対応の2つ目が**永遠に実行されない死にコード** | 旧v95にmap=「タブ1」を送ると別タブが選ばれる |
| **④** | GAS | ①を直しても、URLに #gid が無いと**「タブを特定できません」** | `listSheets_` は `{title, sheets:[…]}` を返すのに、設定処理が**戻り値を配列として誤用** → タブ探索が常に空振り | 旧v95にJだけ応急注入しても「タブを特定できません」 |

つまり――**表の道（新API）は①で死に、裏の道（代替手順）は②で死に、直しても③④が待っている**という多重構造でした。「1つ直しても変わらない」が続いた理由はこれです。

## ✅ v98 の作り＝「100%動く」の根拠

### 三段構え（どの段でも必ず結果が出る）
1. **第一経路**：新API `ext_set_and_import` ＝ **設定→検証→取込を往復1回**で実行（GAS v98）
2. **第二経路**：GASが古い（v95〜v97のまま）なら**自動で旧手順に切替**（タブ一覧→列検出→保存→取込）。旧手順が使う ext_sheets／ext_detect／ext_config_set／ext_import／ext_sync は**旧GASでも無傷**なことをテストで確認済み。**＝ GASを貼り直し忘れても、設定・取込・反映は動きます**
3. **第三経路**：それでも失敗したら**理由別の案内**（共有先アカウントを明記）＋**1手ずつの診断を自動起動**

### ボタンの意味も実務に合わせました
- 未設定の方の行にURLを貼って**「設定」→ 取込まで自動実行**
- URLを貼った状態で**「取込」→ 設定＋取込**、**「反映」→ 設定＋取込＋反映**まで一気に実行
- 実行結果は flash（一瞬）だけでなく、**その方の行の下に緑／赤で残ります**

### 嘘をつかないAPI（一流API流）
- 全応答に **handled / gasVersion** を付与。古いGASの「何もしていないのに ok」成りすましを排除
- 開けない理由を**分類して直し方つき**で返す（権限なし→「○○に編集者で共有」／URL違い→その旨。共有先アカウントは Session から**動的に取得**して案内）
- 変更は**追加のみ**（既存フィールド不変）＝ 旧クライアントを壊しません
- 連携画面の先頭に**サーバー(GAS)版バナー**を常設（v98=緑／旧版=赤＋対処）

## 🆕 v91：v90が60点だった理由

### v90の設計上の誤り
v90は「藤田さんの設定を雛形にして全員へ複製」する方式でした。
しかしこれは **全員が同じスプレッドシートを共有している** という前提です。

**各アポインターが別々のスプレッドシートを持っている場合、全員が藤田さんのシートを見る誤った設定になります。**
取込も反映も、他人のシートに対して行われてしまう——**業務上きわめて危険な状態**でした。

### v91の解決：1人ずつURLを登録できるようにしました
```
📋 スプレッドシートURLをまとめて登録
　各アポインターの元スプレッドシートのURLを貼ってください。
　それぞれ別のシートでも構いません。

　柏木幸代      [ https://docs.google.com/spreadsheets/d/... ]
　竹之内優子    [ https://docs.google.com/spreadsheets/d/... ]
　藤田直美（設定済み・上書きされます）[ ... ]
　小澤幸枝      [ ... ]
　榮智子        [ ... ]

　[ ⚙️ 登録する ]  [ 閉じる ]
```

押すと**1人ずつシートを開いて見出しを読み取り、列を自動判定**します。結果は個別に表示されます。

```
✓ 柏木幸代 ／ タブ「柏木」
　会社名=A 電話=B 担当=C／書き込み先も検出
⚠ 竹之内優子 ／ タブ「リスト」
　会社名=A 電話=B／書き込み先が未検出: 日付・時刻
✗ 榮智子
　開けません（hr.ashikaga@gmail.com への共有をご確認ください）
```

**空欄の方は変更しません**ので、1人ずつ追加していくこともできます。
タブは **URLの #gid → 担当者名のタブ → 唯一のタブ → 先頭タブ** の順で自動選択します。

### 🔎 取り違えチェック（新設）
**「いまの設定を確認」** で、誰がどのスプレッドシートのどのタブを見ているかを一覧表示します。
**同じシートを複数人が参照していれば警告**するので、v90で誤設定してしまった場合もすぐ発見できます。

## ✅ 検証（32/32 合格 ＋ 回帰80項目）
**新機能 32項目**：URLの読み取り（通常・#gid・?gid・IDのみ・空欄・無関係な文字列）／列の判定（そろえばOK・書き込み先が無ければ警告つきで通す・会社名や電話が無ければNG・理由の返却・開けない場合）／**各自が別のスプレッドシートでも設定できること**（3名それぞれ別IDが保持される）／タブの自動選択（唯一のタブ・担当者名のタブ・gid指定）／**同じシートをタブで分ける運用**／入力の誤りを個別に報告（空欄・URL不正・名簿外・開けない）／**取り違えの検知**（同一シート同一タブのみ重複、タブが違えば重複でない）。

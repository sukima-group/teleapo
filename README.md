## 設定（ここだけ書き換えます）

メールアドレス・PIN・名簿・シートIDは、ファイル冒頭の設定ブロックだけに書いてあります。

- **gas-code.txt** の `CONFIG`
  - `SHEET_ID` / `ADMIN_SHEET_ID`：スプレッドシート
  - `NOTIFY.SHIFT_TO`：シフト申請の通知先（管理者）。ほかの通知先も `NOTIFY` の中
  - `NOTIFY.RETRY_MAX` / `NOTIFY.RETRY_BASE_MIN`：再送の回数と間隔
  - `ADMIN_PIN`：管理者PIN（画面側と同じ値にする）
  - `ROSTER`：在籍中のアポインター（PIN・氏名・タブ名・メール）。`FORMER_MEMBERS`：以前の在籍者
  - `ADMIN_GUARD`：`true` にすると、管理者用の操作に管理パスコードが必要になります（既定は `false`＝従来どおり）
- **index.html** の `CONFIG`
  - `GAS_URL`：サーバーのURL
  - `ADMIN_PIN`：サーバーと同じ値
  - `STAFF_DEFAULT`：名簿の初期値（サーバーの名簿が届くまでの表示用）

## 導入手順

1. **控えを取る**：メインと管理者用のスプレッドシートは、ファイル → 版の履歴 で今の版に名前を付けておきます。
2. **GAS**：「コード.gs」を全消去 → `gas-code.txt` を貼り付け → 保存。
3. **GAS**：関数 `setupNotifyRetry` を1回実行します（通知の自動再送を10分ごとに動かす設定。権限の確認が出たら許可）。
4. **GAS**：デプロイ → デプロイを管理 → 編集 → バージョン「新バージョン」→ デプロイ。URLは変わりません。
5. **GitHub**：index.html・sw.js・README.md を Commit します。**tests フォルダは上げないでください**。
6. **各端末**：アプリを開き「🔄 最新の状態に更新」を押します。
7. **管理画面で確認**：先頭の状態の帯を見ます。
   - 「名簿」が「確認事項」になっている場合：PIN 095 を以前の方が使っている表示です。内容を確認し「PINを引き継ぐ」を押します。
   - 「通知メール」：「✉ テスト通知」で届くか確かめます。
8. **柏木さんの連携**：外部連携の一覧で柏木さんの「取込」を押すと、取り込み元・取り込み先・件数の確認画面が出ます。内容を確かめて「取り込む」。

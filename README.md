## 🆕 v101：v100が60点だった理由

v100で名簿はシート化しましたが、**「名簿・録音・KPI・経営システム・夜間処理が本当に全部つながっているか」を確かめる手段がありませんでした**。
導入手順が「①→②→③を押して、KPIを集計して、反映して…」と多く、**どこまで済んでいて、何が残っているのか**が分かりません。
これでは、何かが抜けていても気づけません。

### 解決：🩺 総合診断（管理画面の一番上）
ボタン1つで、次を**すべて点検**し、未完了の項目と**直す場所**を示します。

```
🩺 総合診断                                75点　未完了の項目があります

基盤
　✓ アプリ版とサーバー版の一致    アプリ v101 ／ サーバー v101
名簿
　✓ 稼働中のアポインター          5名（退職2名）
　✓ 柏木幸代（091）               メール登録済み
　△ 中村花林（112）               会社Gmail未登録
　　→ 名簿の「編集」からメールを入れてください
KPI
　✓ KPI目標の設定                 5名分あり
録音
　△ 録音フォルダ                  未作成: 田中久美子
　　→ 「🆕 ② 新メンバーの初期設定」を押してください
　✓ 全体保管庫                    通話録音保管庫
連携
　△ 元スプレッドシート連携        未設定: 田中久美子・片山佳代
　　→ 「🔗 元スプレッドシート連携」で各自のURLを登録してください

　× 経営管理システムの設置        未設置
　　→ 「📊 作成／更新する」を押してください

```

**✓＝正常／△＝注意（動くが未完）／×＝未完了（動かない）**
**× と △ には「→ 直す場所」が必ず付きます。**上から順に潰せば、全項目 ✓ になります。

### 点数の意味
✓を1点、△を0.5点として100点満点で表示します。**100点＝すべてつながっている状態**です。

### ログイン画面にも名簿の状態を表示
```
版 v101　／　名簿 5名（サーバー同期済み）
```
「前回の名簿」と出る場合は、まだサーバーから取得できていません（オンラインで開き直してください）。

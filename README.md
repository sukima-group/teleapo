### ⑹ 通話録音：ご指定のドライブへ、強制的に自動保存（条件８）

**Galaxy A25 で調べたこと**（出典は末尾）

- 通話の自動録音は、Samsung の「電話」アプリの設定（︙ → 設定 → 通話を録音 → 通話の自動録音 → ON）で、すべての通話・未登録の番号などを選べます。ON にすると、通話が終わるたびに録音が保存されます。
- 録音のファイルは、内部ストレージの「Recordings › Call」に入ります（One UI 4.0 から、Android の決まりでこの場所になりました）。
- Android の Chrome は、バージョン 132（2025年1月）から、ウェブのアプリがフォルダを読める（File System Access）ようになりました。このアプリは、この仕組みで「Call」のフォルダを読み、録音を会社のドライブへ送ります（v109〜）。
- **ブラウザで動くアプリからは、電話アプリの「通話の自動録音」を ON にできません**。また、One UI 7 に上げたあと通話の録音が無くなったという報告が、海外のモデルでありました（地域による違い。日本のモデルについての報告は見つかりませんでした）。

**v117 で「強制」にしたこと**

| 場面 | 動き（Android・録音の自動保存が「必須」のとき） |
|---|---|
| ホーム | 自動保存がつながっていない（フォルダをつないでいない・許可が外れた）ときは、赤い帯で知らせます |
| 発信 | 発信ボタン・リストの発信・再架電のお知らせ・おいでんの発信・オートコール・キーボードからの発信の **どれも、発信の前に止めます**。「🎙 はじめの設定を始める（約2分）」（自動録音の ON から案内）または「🔓 1回タップして再開」。つながると「📞 発信する」で、そのまま発信できます |
| どうしても録音なしで発信するとき | 理由を書くと、**30分のあいだ** 発信できます。理由は監査ログに残し、**管理者にメール**（発信・退勤それぞれ1日1通）で知らせます |
| 退勤 | 退勤を押すと、**きょうの録音を送り終えてから** 退勤の確認に進みます。送れていない録音があるときは「もう一度送る」。送れないまま退勤するときは理由（管理者へ） |
